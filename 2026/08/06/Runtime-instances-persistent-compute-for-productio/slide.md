# Amazon Bedrock AgentCore のランタイムインスタンス
本番環境の AI エージェント向け永続的コンピュート

**発表日: 2026年8月6日**

---

## 概要

### Runtime instances の3つの主要特徴

- **エージェント間の協調作業**: 複数のエージェントが最大14日間にわたって共有インフラストラクチャ上で協調作業可能
- **AWS管理のインフラ**: EC2ベースのAWS管理インフラストラクチャで高可用性を実現
- **セッションの永続性**: サーバーレスではなくEC2インスタンスを活用し、複数日間のワークフローに対応

### サポート機能

- **GPUアクセラレーション**: 高度な計算タスクに対応
- **セッション管理**: 停止・再開機能で柔軟な運用が可能
- **コンテナ化デプロイメント**: 既存のコンテナワークフローと統合

---

## 前提・背景

### 市場の動向

- AI エージェントの複雑化に伴い、長期実行ワークフローへの需要が増加
- マルチエージェント調整による複合タスク処理の需要拡大
- GPU を活用した高度な推論・処理能力の要求

### Amazon Bedrock AgentCore の進化

- Runtime microVMs との組み合わせで多様なユースケースに対応
- サーバーレスと永続コンピュートの選択肢を提供
- エンタープライズ向けAI エージェントプラットフォームの確立

### 課題解決

- **複数日ワークフロー**: 従来のサーバーレスでは対応困難な長時間実行に対応
- **マルチエージェント調整**: 複数エージェント間の状態共有と協調を効率化
- **GPU処理**: 高度な計算タスクをネイティブにサポート

---

## 変更内容・新機能

### 1. Runtime instances コンピュート オプション

- Amazon Bedrock AgentCore に新たに追加されたコンピュート選択肢
- AWS 管理の EC2 インフラストラクチャを活用
- 複数エージェントを単一ランタイムにデプロイ可能

### 2. セッション・ワークフロー機能

- **最大14日間の持続セッション**: 複数日実行ワークフローに対応
- **セッション停止/再開**: 柔軟な実行制御で運用効率を向上
- **共有ファイルシステム**: エージェント間でのデータ共有を実現

### 3. インフラストラクチャ機能

- **GPUアクセラレーション**: GPU対応インスタンスタイプで高速処理
- **ARM64 および x86_64 対応**: 幅広いアーキテクチャをサポート
- **Python 3.11-14 対応**: 最新Python環境での開発に対応

- **開発の柔軟性**: コンテナ化デプロイメントで既存ツールと統合

## ユースケース例

### 1. インテリジェント コード処理エージェント

- コード生成エージェント + コードレビューエージェント
- 共有ファイルシステムを通じた協調作業
- 複数日間のコード開発・レビュー・改善サイクルの自動化

### 2. 複雑なデータ分析・レポート生成

- データ取得エージェント + 分析エージェント + レポート生成エージェント
- GPU を活用した高度な統計処理
- 大規模データセットに対する効率的な処理

### 3. エンタープライズ ワークフロー自動化

- 承認フロー、スケジューリング、通知エージェントの協調
- 複数日間にわたる業務プロセスの完全自動化
- SLA 管理、監査ログの自動記録

## 技術仕様

### 対応環境

| 項目 | 仕様 |
|------|------|
| **プログラミング言語** | Python 3.11 - 3.14 |
| **CPU アーキテクチャ** | ARM64、x86_64 |
| **GPU対応** | NVIDIA GPU インスタンスタイプ対応 |
| **セッション持続時間** | 最大14日間 |
| **リージョン対応** | 複数の AWS リージョンで利用可能 |

### Runtime instances vs Runtime microVMs

| 特性 | Runtime instances | Runtime microVMs |
|------|------------------|------------------|
| **実行時間** | 最大14日間 | 短時間実行 |
| **リソース** | EC2ベース | サーバーレス |
| **マルチエージェント** | ネイティブサポート | 分離実行 |
| **用途** | 長期ワークフロー | 軽量タスク |
