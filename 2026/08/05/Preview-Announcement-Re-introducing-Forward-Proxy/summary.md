# AWS Network Firewall がフォワードプロキシ機能として再提供開始

[Preview Announcement] Re-introducing Forward Proxy as AWS Network Firewall Functionality

**カテゴリ:** What's New
**公開日:** 2026-08-04T22:24:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-network-firewall-forward-proxy-preview/)

このページでは、AWS What's Newで発表された「[Preview Announcement] Re-introducing Forward Proxy as AWS Network Firewall Functionality」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

AWS Network Firewallがno-source-preservation展開モードでフォワードプロキシ機能として再導入され、既存のすべてのファイアウォール機能を保持したまま、単一のセキュリティポリシーで透過型ファイアウォールとの統合運用が可能になりました。このアップデートは、集中化されたセキュリティ制御を必要とする企業や、データ流出防止とマルウェア注入対策を強化したい組織に適しています。

## このアップデートで何が変わったか

- AWS Network Firewallが明示的フォワードプロキシ機能として再導入されました。
- 既存のNetwork Firewallのすべてのフィルタリング機能と特性をフォワードプロキシとして利用できるようになりました。
- 2025年11月25日のプレビュー時は独立した製品でしたが、顧客フィードバックに基づいて統合されました。
- no-source-preservation展開モードで、既存のFirewallポリシーを使用してフォワードプロキシとして構成できます。
- マネージドルールグループ、アクティブ脅威防御、Geo-IPフィルタリング、URLおよびドメインカテゴリフィルタリング、Amazon EKSおよびAmazon ECSのコンテナ属性ベースルールなどすべての機能が利用可能です。
- 単一のセキュリティポリシーで明示的プロキシと透過型ファイアウォール両方の機能を使用できます。
- 現在、米国東部（オハイオ）リージョンでパブリックプレビュー中です。
- パブリックプレビュー期間中は無料で利用できます。
