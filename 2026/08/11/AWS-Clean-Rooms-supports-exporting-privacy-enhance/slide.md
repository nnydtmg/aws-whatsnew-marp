# AWS Clean Rooms がプライバシー強化分析ログのエクスポートに対応

AWS Clean Rooms supports exporting privacy-enhanced analysis logs for SQL

**What's New** | 2026-08-11T12:00:00

---

## 概要

- AWS Clean Rooms は、SQL 分析のプライバシー強化分析ログを S3 にエクスポートする機能を新たに提供開始いたしました。
- このアップデートにより、複数企業間でのデータコラボレーション時に、Spark 実行詳細を確認してクエリの最適化とコスト削減が可能になります。

---

## 前提・背景

### これまでの課題

- クエリのパフォーマンス問題をトラブルシューティングする際に役立ちます。
