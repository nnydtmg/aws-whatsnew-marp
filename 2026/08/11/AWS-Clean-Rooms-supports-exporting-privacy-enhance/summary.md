## 要約

AWS Clean Rooms は、SQL 分析のプライバシー強化分析ログを S3 にエクスポートする機能を新たに提供開始いたしました。このアップデートにより、複数企業間でのデータコラボレーション時に、Spark 実行詳細を確認してクエリの最適化とコスト削減が可能になります。

## このアップデートで何が変わったか

- このアップデートは、複数企業間でデータを共有しながら分析する必要があるユーザーに適しています。

## 詳細

- AWS Clean Rooms は SQL 分析のプライバシー強化分析ログをエクスポートできるようになりました。

- S3 バケットにプライバシー強化分析ログをエクスポートして、Spark 実行の詳細情報を確認できます。

- コラボレーション所有者がメンバーにログエクスポート機能を付与することができます。

- クエリ実行後、希望する S3 パスにプライバシー強化分析ログをエクスポート可能です。

- データスキューなどの異常を特定し、クエリの最適化とコスト削減が実現できます。

- このアップデートは、複数企業間でデータを共有しながら分析する必要があるユーザーに適しています。

- 特に、測定プロバイダーと出版社などのコラボレーション関係にある組織に有用です。

- クエリのパフォーマンス問題をトラブルシューティングする際に役立ちます。
