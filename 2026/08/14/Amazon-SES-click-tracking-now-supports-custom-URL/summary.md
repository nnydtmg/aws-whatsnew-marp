# Amazon SES のクリックトラッキングがモバイルアプリのカスタムURL対応に

Amazon SES click tracking now supports custom URL paths for mobile app deep linking

**カテゴリ:** What's New  
**公開日:** 2026-08-14  
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-ses-supports-customurl-deeplinking)

このページでは、AWS What's Newで発表された「Amazon SES click tracking now supports custom URL paths for mobile app deep linking」の内容を日本語で要約しています。

---

## 要約

Amazon SES は新しい **ses:custom-path HTML 属性**により、モバイルアプリのディープリンキング機能をサポートし、エンゲージメントトラッキングを維持したまま iOS および Android のアプリ連携を実現いたしました。本機能は、カスタムリダイレクトドメインと適切な検証ファイルを設定することで、すべての AWS リージョンでご利用いただけます。

---

## 何が変わったか

### 主な変更点

1. **新規属性の追加**
   - ses:custom-path HTML 属性をサポート
   - メール内の <a> タグに属性を追加するだけで利用可能

2. **ディープリンキングの強化**
   - iOS の Universal Links に対応
   - Android の App Links に対応
   - パスセグメント情報をトラッキング URL に保持

3. **トラッキング機能との両立**
   - エンゲージメントトラッキングを無効化する必要がなくなった
   - 従来のトラッキング機能を維持しながらディープリンクを使用可能

4. **グローバル可用性**
   - Amazon SES が利用可能なすべての AWS リージョンで提供開始

---

## 詳細説明

### ses:custom-path 属性とは

- ses:custom-path: パスセグメントを指定
- SES がこのセグメント情報をトラッキング URL に統合
- モバイルOS がトラッキングパスとアプリのURLスキームをマッチング

### 必要な設定

#### 1. カスタムリダイレクトドメイン
- クリックトラッキング用のカスタムドメインを設定
- SES のドメイン設定で有効化

#### 2. 検証ファイルの配置

**iOS の場合:**
https://redirect.example.com/.well-known/apple-app-site-association

**Android の場合:**
https://redirect.example.com/.well-known/assetlinks.json

### 実装のステップ

#### ステップ 1: Amazon SES でドメイン設定
1. AWS マネジメントコンソール → Amazon SES
2. Verified identities または Identity Management で設定
3. カスタムリダイレクトドメインを指定
4. DNS レコード (CNAME) を設定

#### ステップ 2: 検証ファイル配置
- アプリ配信企業（Apple / Google）の指示に従ってファイルを配置
- ドメイン配下の .well-known ディレクトリに設置

#### ステップ 3: HTML メールの編集
- <a> タグに ses:custom-path 属性を追加
- パス値を指定すると自動的にトラッキング URL に統合

## メリット・効果

### ユーザー体験の向上

1. **シームレスなアプリ遷移**
   - メール内のリンク → アプリの指定ページに直接遷移
   - ストアを経由する必要がない

2. **コンテキスト保持**
   - パスセグメント保持により正確なページへ誘導
   - ユーザーが探していたコンテンツにすぐアクセス可能

3. **エンゲージメント計測**
   - クリックトラッキングを継続して実施
   - メルマガの効果測定をより正確に実施可能

### ビジネス面でのメリット

1. **コンバージョン率向上**
   - Email-to-app のコンバージョンレート: 17.7%
   - 従来の汎用リンク: 約 5% の CVR
   - 約 3.5倍のコンバージョン率改善が期待可能

2. **リテンション向上**
   - アプリ内への直接誘導でアプリ利用頻度が向上
   - ユーザーエンゲージメント向上

3. **マーケティング効果の最大化**
   - より正確なエンゲージメント分析が可能
   - キャンペーンの最適化が容易

## 利用シーン

### 1. Eコマース・小売業

**シナリオ:**
- 限定セール情報をメール配信
- ユーザーがメール内のリンクをクリック
- アプリが開き、該当商品ページが表示される
- トラッキングデータで「セールメール → 商品閲覧 → 購入」を計測

### 2. 放棄カート復帰キャンペーン

**シナリオ:**
- 放棄されたカートの内容をメール配信
- メール内のリンクをクリック
- アプリが開き、カートの内容が表示される
- チェックアウトまでの導線が短縮される

### 3. パーソナライズド コンテンツ配信

**シナリオ:**
- ユーザーセグメント別に異なるコンテンツのリンクを配信
- 各セグメントの行動パターンをディープリンク + トラッキングで分析
- キャンペーン効果を セグメント別に計測

### 4. 再エンゲージメント キャンペーン

**シナリオ:**
- アプリを未使用のユーザーにメール配信
- アプリ内の新機能や特典ページへのディープリンクを提供
- ユーザーの再利用を促進

## 注意点・制限事項

### 必須要件

1. **カスタムリダイレクトドメインの設定が必須**
   - デフォルトドメイン では利用不可
   - CNAME設定が必要

2. **iOS / Android の検証ファイル配置**
   - AASA / assetlinks.json の設定が必須
   - 設定なしではアプリが起動しない

3. **HTML メール形式が必須**
   - テキスト形式のメールでは利用不可

### 互換性

- 古いバージョンのアプリでは機能しない場合がある
- アプリの更新を促進する必要がある場合も
