# Amazon Quick が Microsoft Purview との統合でデータ損失防止に対応

Amazon Quick now supports data loss prevention with Microsoft Purview

**カテゴリ:** What's New
**公開日:** 2026年8月14日
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-quick-dlp-purview/)

---

## 要約

Amazon Quickが新たにMicrosoft Purviewとの統合によるデータ損失防止機能に対応しました。既存のPurview感度ラベルをQuick環境に適用して、機密ファイルの共有を制御できるようになりました。

これにより、IT管理者とセキュリティチームは、追加ツールなしに既存のガバナンスポリシーをQuickに拡張し、チャット、スペース、ナレッジベースなど様々な機能において細粒度のデータ保護を実現できます。

---

## このアップデートで何が変わったか

### Microsoft Purview との統合

- Amazon Quickが、Microsoft Purviewとの統合により、データ損失防止（DLP）ポリシーの実行に対応するようになりました
- Purviewの感度ラベルをQuickのチャット、スペース、ナレッジベースなどの機能に自動的に適用して、ファイルの取り扱いを制御できます

### 細粒度のデータ保護制御

- IT管理者とセキュリティチームは、各感度ラベルに対して実行アクション（ブロック、警告、許可）を設定し、機密ファイル共有に対する細粒度の制御が可能です
- 例えば、金融サービス企業は「極秘」ラベルのファイルを共有スペースへのアップロードをブロックしながら、「内部」ファイルには警告通知を付けて許可することができます

### グローバル対応

- この機能は、Amazon Quickのエージェント機能がサポートされているすべてのAWSリージョンで利用可能です
- 既存のMicrosoft Purviewガバナンスポリシーを、追加ツールなしにQuickに拡張できます

### 主な対象ユーザー

- **IT管理者**: ガバナンスポリシーの一元管理が可能

## 主な特徴

### 1. Purview 感度ラベルの自動適用

- Quick のチャット、スペース、ナレッジベースに Purview 感度ラベルを自動的に適用
- ファイルの取り扱いを自動制御
- 手動設定の手間を削減

### 2. 実行アクションの細粒度制御

- **ブロック**: 極秘ファイルの共有スペースアップロードを禁止
- **警告**: 内部ファイルに警告通知を付けて許可
- **許可**: 機密度に応じた柔軟な制御

### 3. 既存ガバナンスポリシーの継承

- 追加ツール導入不要で既存の Microsoft Purview ガバナンスポリシーを Quick に拡張
- 運用負荷を最小化しながらセキュリティ強化

### 4. グローバル対応

- Amazon Quick のエージェント機能がサポートされるすべての AWS リージョンで利用可能
- マルチリージョン展開に対応
