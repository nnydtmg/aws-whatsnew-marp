# Amazon Bedrock が SpaceXAI Grok 4.6 をサポート開始

Amazon Bedrock now supports SpaceXAI Grok 4.6

**カテゴリ:** What's New
**公開日:** 2026-08-19
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-bedrock-grok-4-6/)

---

## 要約

Amazon Bedrockが、SpaceXAIの最新フラグシップモデルである Grok 4.6 をサポートするようになりました。Grok 4.6 は 500K のコンテキストウィンドウと設定可能な推論努力レベル（低、中、高、超高）を備えており、複雑なマルチステップタスクに対応する必要があり、エンタープライズグレードのセキュリティとスケーラビリティを求める開発者や企業に最適です。

---

## このアップデートで何が変わったか

### 新機能・強化点

1. **Grok 4.6 モデルのサポート**
   - SpaceXAI の最新フラグシップモデルが Amazon Bedrock で利用可能に
   - 複数の業界ベンチマークで高い性能を実現

2. **500K トークンのコンテキストウィンドウ**
   - 大規模なコード分析、ドキュメント処理に対応
   - 複雑で長期的なタスクの実行が可能

3. **設定可能な推論努力レベル**
   - **低**: 迅速な応答が必要なシナリオ
   - **中**: バランスの取れた性能と速度
   - **高**: 複雑な問題解決
   - **超高**: 最高精度が必須のタスク

4. **エンタープライズグレードの機能**
   - セキュリティとプライバシー保護
   - 包括的な監視とロギング
   - AWS リージョン全体でのスケーリング柔軟性

## 技術仕様

### Grok 4.6 の特性

| 項目 | スペック |
|------|----------|
| **コンテキストウィンドウ** | 500K トークン |
| **推論努力レベル** | 低、中、高、超高 |
| **知識カットオフ** | 2026年2月1日 |
| **API 価格** | $2/$6 per 1M tokens (入力/出力) |
| **特徴** | 長期実行エージェント、複雑なコーディング、知識作業 |

### ベンチマーク性能

- Artificial Analysis Intelligence Index: **61**（GPT-5.6 Sol と同等）
- 知識作業とコーディング分野で特に強い
- Grok 4.5 から 5 ポイント向上
