# Amazon Quick のカスタム権限にデフォルト拒否機能を追加

Amazon Quick adds deny by default for custom permissions

**カテゴリ:** What's New
**公開日:** 2026-08-19
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-quick-deny-by-default/)

---

## 要約

Amazon Quickのカスタム権限にデフォルト拒否機能が追加され、管理者は新しいAI機能をリリース前に制限し、準備ができたときに明示的に許可することが可能になりました。この更新は、セキュリティとガバナンスを重視する組織のIT管理者やセキュリティチームに特に有益です。

---

## このアップデートで何が変わったか

### 新機能: デフォルト拒否

- Amazon Quickのカスタム権限に「デフォルト拒否」という新しいガバナンス設定が追加
- 新しいAI機能がユーザーに到達する前に自動的に制限される

### 従来との違い

**従来:**
- 新しいAI機能がリリース時にすべてのユーザーが利用可能
- 管理者が事後対応で機能を制限する必要あり
- セキュリティとコンプライアンスのリスク

**新方式:**
- 管理者が事前にカテゴリを制限
- リリース時に新しいAI機能を自動的に拒否
- 準備ができたときに各機能を明示的に許可

## 主な機能

### カスタム権限プロファイルでの制御

- **AI機能カテゴリの制限**: AI機能カテゴリ全体を制限可能
- **スコープ設定**: ユーザー、ロール、またはアカウント全体に適用
- **既存機能への影響**: カテゴリを制限すると既存機能も制限される

### 柔軟な許可管理

- **段階的な展開**: 管理者が準備ができたときに各機能を許可
- **プロファイル単位**: 制限はプロファイルごとに独立して適用
- **複数ポリシー**: 異なるユーザーグループに異なるポリシーを適用可能

### 利用可能性

- **グローバル展開**: Amazon Quickが利用可能なすべてのAWSリージョンで使用可能
- **設定方法**: 「Manage account」またはAWS CLIから設定

## 設定方法

### 基本的な流れ

1. **カスタム権限プロファイルの作成**
   - Amazon Quick の「Manage account」にアクセス
   - 新しいプロファイルを作成

2. **AI機能カテゴリの制限**
   - ガバナンス設定で「デフォルト拒否」を有効化
   - AI機能カテゴリを制限対象に設定

3. **ユーザーへの割り当て**
   - ユーザー、ロール、またはアカウント全体に割り当て
   - 複数のプロファイルを組み合わせ利用も可能

4. **明示的な許可**
   - 準備完了後、必要な機能を許可に変更
   - CLIで機能の許可状態を管理

### AWS CLI での設定例

```bash
aws quicksight update-custom-permissions \
  --aws-account-id ACCOUNT_ID \
  --custom-permissions-name "RestrictAI-Finance" \
  --capabilities '{"Research": "ALLOW", "Topic": "ALLOW"}' \
  --governance '{"DefaultCategoryEffects": {"AI": "DENY_BY_DEFAULT"}}'
```
