# AWS Transform の継続的現代化機能が全リージョンで一般提供開始

AWS Transform continuous modernization is now generally available

**カテゴリ:** What's New
**公開日:** 2026-08-03T21:15:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/7/aws-transform-continuous-general-available)

このページでは、AWS What's Newで発表された「AWS Transform continuous modernization is now generally available」の内容を日本語で要約し、スライド形式で確認できます。

## 要約

AWS Transform の継続的な現代化機能が全リージョンで一般提供開始となり、エンジニアリングチームがソースコードリポジトリの技術的負債を大規模に分析・改善できるようになりました。ウェブアプリケーション、IDE、ターミナルなど複数のインターフェースから、複数のソースコードプロバイダーと連携して、自動的にコード改善提案を生成・管理することができます。

## このアップデートで何が変わったか

- AWS Transform の継続的な現代化機能が、AWS Transform がサポートされているすべての AWS リージョンで一般提供されるようになりました。

## 詳細

- AWS Transform の継続的な現代化機能が、AWS Transform がサポートされているすべての AWS リージョンで一般提供されるようになりました。

- ソースコードリポジトリ全体の技術的負債を分析・改善するための機能です。

- GitHub 組織、GitLab グループ、Bitbucket ワークスペースに接続できます。

- オンデマンドまたは定期的なスケジュールで分析を実行することができます。

- 技術的負債、セキュリティ、エージェント対応状況、現代化対応状況、カスタム分析基準に基づいて結果を優先順位付けできます。

- AWS Transform ウェブアプリケーションから直接、ソースコードプロバイダーの接続、分析の実行・スケジュール設定、結果の確認、改善策の作成ができます。

- 改善策がある場合、検証済みのコード変更を含むブランチとプルリクエストまたはマージリクエストが自動的に作成されます。

- 分析と改善は AWS アカウント内で実行され、ソースコードはユーザーの管理下に置かれます。

- AWS Transform Kiro Power、エージェントプラグイン、AWS Transform CLI を使用して、IDE やターミナルから作業することも可能です。

- ローカルリポジトリの分析、ラベルを使用したリポジトリの整理、Amazon EC2 または AWS Batch を使用したローカルまたはリモート分析の実行ができます。
