# Amazon Bedrock AgentCore runtime instances が一般提供開始

AgentCore runtime instances are now generally available

**カテゴリ:** What's New
**公開日:** 2026-08-06T20:00:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-bedrock-agentcore-runtime-instances-generally-available/)

このページでは、AWS What's Newで発表された「AgentCore runtime instances are now generally available」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

Amazon Bedrock AgentCoreの新しいruntime instancesにより、EC2インスタンス上でエージェントを実行でき、インフラストラクチャ管理の負担が軽減されます。このアップデートは、リソース集約的で長時間実行が必要なエージェントを運用するチームに特に適しており、幅広いEC2インスタンスタイプと最大14日間のセッション対応により、柔軟なエージェント運用が実現できます。

## このアップデートで何が変わったか

- Amazon Bedrockの新しいAgentCore runtime instancesが一般提供されるようになりました。
- EC2インスタンス上でエージェントを実行でき、インフラストラクチャ管理が不要になります。
- GPU加速、メモリ最適化、コンピュート最適化など、幅広いEC2インスタンスタイプをサポートしています。
- 最大14日間の長時間実行エージェントセッションに対応しており、既存のマイクロVM方式は最大8時間です。
- AWS Management Console、CLI、SDK、APIを使用してキャパシティプロバイダーを作成し、エージェントをアタッチできます。
- 米国、アジア太平洋、ヨーロッパの9つのAWSリージョンで利用可能です。
- このアップデートは、リソース集約的、長時間実行、または特殊なハードウェアが必要なエージェントを運用するチームに適しています。
- AWS側がプロビジョニング、パッチ適用、スケーリング、ライフサイクル管理を自動で行います。
- EC2コストに加えて、コンピュート管理費用が発生します。
