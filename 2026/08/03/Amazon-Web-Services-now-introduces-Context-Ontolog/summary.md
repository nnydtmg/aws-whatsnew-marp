## 要約

Context Ontology Acceleratorは、AIエージェントが正確で一貫性のある説明可能な意思決定を行うために必要なビジネスオントロジーを数ヶ月ではなく数日で構築できるオープンソースツールです。このアップデートは、複数のシステムに散在するデータを統合し、AIエージェントの信頼性と監査可能性を確保したい組織に特に有益です。

## このアップデートで何が変わったか

- Amazon Neptune、Amazon OpenSearch Serverless、Amazon Bedrockを使用して構築されており、GitHubでApache 2.0ライセンスで利用可能です。

## 詳細

- Context Ontology Acceleratorは、組織がビジネスのオントロジー（製品、顧客、ポリシー、運用ルールの機械可読モデル）を構築するのを支援するオープンソースアクセラレーターです。

- このツールは構造化および非構造化データソースに接続し、AIを使用してオントロジーを作成し、ドメイン専門家がレビュー、編集、承認することができます。

- 承認されたオントロジーはW3C標準で表現された知識グラフに保存され、Model Context Protocol（MCP）サーバーを通じてエージェントが利用できます。

- 従来は数ヶ月かかるオントロジー作成プロセスを数日に短縮することができます。

- Amazon Neptune、Amazon OpenSearch Serverless、Amazon Bedrockを使用して構築されており、GitHubでApache 2.0ライセンスで利用可能です。

- AIエージェントの意思決定に対する信頼性と説明可能性、監査可能性を必要とする組織に適しています。

- データソース間のスキーマの競合と命名規則の不一致を解決する必要がある組織に有効です。

- AIエージェントをProof of Conceptから本番環境へ移行させたい組織に最適です。
