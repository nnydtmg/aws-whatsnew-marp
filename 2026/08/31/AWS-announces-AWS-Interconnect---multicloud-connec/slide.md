# AWS Interconnect - Microsoft Azure マルチクラウド接続がプレビュー開始

AWS announces AWS Interconnect - multicloud connectivity with Microsoft Azure in preview

**What's New** | 2026-08-31

---

## 概要

- AWSはMicrosoft AzureとのAWS Interconnectマルチクラウドのパブリックプレビューを発表しました。
- お客様は単一の管理体験で接続を容易に管理できます。

## 変更内容・新機能

新しい機能はAWS Interconnect - マルチクラウドとMicrosoft Azureのパブリックプレビューです。この機能は複数のクラウド間で耐障害性が高くスケーラブルなプライベート接続を迅速にプロビジョニングすることを可能にします。本アップデートはマルチクラウド戦略を採用しAWSとAzure間で運用するお客様に適しています。
