# Amazon Bedrock AgentCore の Web Search
ドメイン・公開日フィルタリング対応、欧州・アジア太平洋地域に展開

**発表日: 2026年8月19日**

---

## 概要

### 主な3つの強化ポイント

- **ランタイムドメインフィルタリング**: 信頼できるソースに検索結果を限定し、不要なドメインをブロック
- **公開日フィルタリング**: 特定の時間枠内の最新で関連性の高い情報のみを取得
- **地域展開**: アイルランド（eu-west-1）、東京（ap-northeast-1）を含む欧州・アジア太平洋地域で利用可能

---

## 前提・背景

### 市場の課題

- AI エージェントが外部情報にアクセスする必要性が高まる一方、情報ソースの信頼性と鮮度の制御が課題
- 規制産業では、使用データソースの厳密な管理が必須
- 研究ワークフローでは、最新で検証済み情報へのアクセスが重要

### Amazon Bedrock AgentCore の進化

- Web Search ツール（GA）により、エージェントが現在の正確な知識に基づいて対応可能に
- モデルコンテキストプロトコル（MCP）を使用した統合接続
- データ流出ゼロの安全な実装

---

## 新機能：ドメインフィルタリング

### ランタイムドメインフィルタリング

- **リクエストごとのカスタマイズ**: エージェントがリアルタイムで検索対象ドメインを指定
- **ホワイトリスト機能**: 信頼できるソースのみに絞り込み
- **ブラックリスト機能**: 不要なドメインを動的に除外

### ゲートウェイレベル管理

- **アローリスト機能**: 管理者が事前に許可ドメインを設定
- **ドメイン上限拡張**: 従来の制限から大幅に拡張（リストあたり最大100ドメイン）

---

## 新機能：公開日フィルタリング

### 時間枠指定による精密な情報取得

- **期間指定検索**: 特定期間内のコンテンツのみに限定
- **タイムリーな情報**: 常に最新のニュースや情報を優先
- **規制対応**: 古い・非推奨情報の除外が可能

### 利用例

- **金融・規制**: 直近3ヶ月の認可情報のみ参照
- **医療・研究**: 直近1年の査読済み論文から検索
- **ニュース・分析**: 過去24時間のトレンド情報に集中

---

## 地域拡大と利用可能性

### 新規提供地域

| 地域 | リージョン |
|-----|----------|
| **ヨーロッパ** | アイルランド（eu-west-1） |
| **アジア太平洋** | 東京（ap-northeast-1） |

### グローバル展開状況

- 米国で既に GA 済み
- 最新のコネクタ（v1.2.0）で全機能を提供
- 今後さらなる地域への展開予定

## パフォーマンス向上

### 最適化の成果

- **セッション内の順序的呼び出し**: **25～35%高速化**
- **認証トークン キャッシング**: 30分間の有効期間全体を活用
- **プラットフォーム オーバーヘッド削減**:
  - PDX：35%削減
  - IAD：25%削減
  - その他地域：12～18%削減

## ユースケース

### 規制産業への適用

- **金融機関**: コンプライアンス規制の最新情報のみに基づく意思決定支援
- **医療・ライフサイエンス**: 査読済み論文や認可情報への限定アクセス

### 研究ワークフロー

- **学術機関**: 特定期間の査読済み論文から自動的に最新知見を抽出
- **企業研究**: 信頼できる情報源に限定した競合分析

### エンタープライズ・システム

- **コンテンツ分析**: 社内ドメイン + 承認外部サイトのハイブリッド検索
- **コンプライアンス監視**: 規制当局の公式発表のみを参照

## 実装のメリット

### データセキュリティ

- **ゼロデータ流出**: AWS 環境内で完全に処理
- **データレジデンシ**: 顧客の安全な環境内に保持

### 運用効率

- **管理の簡素化**: ゲートウェイレベルで一元管理
- **信頼性の向上**: 既知の情報ソースのみを活用
- **コスト最適化**: 不要な検索結果の処理削減

### ビジネス価値

- **規制遵守**: ポリシーに基づく厳密な情報制御
- **精度向上**: ノイズの少ない高品質な検索結果
- **スケーラビリティ**: 増加するエージェント負荷に対応

---

## まとめ

### Amazon Bedrock AgentCore Web Search の新段階

- **精密なフィルタリング**: ドメイン・公開日による多層制御
- **グローバル対応**: 欧州・アジア太平洋での利用が可能に
- **エンタープライズ向け**: 規制産業や研究機関のニーズに完全対応

### 次のステップ

1. **要件分析**: 自社ワークフローで必要なフィルタリング条件を特定
2. **パイロット実施**: ドメイン・日付フィルタを設定してテスト
3. **本番展開**: 既存エージェントを段階的に移行
4. **監視・最適化**: ログから効果を測定し、ポリシーを調整
