# Amazon Bedrock AgentCore の Web Search がドメイン・公開日フィルタリングに対応、欧州・アジア太平洋地域に展開

Web Search in Amazon Bedrock AgentCore adds domain and published date filtering, expands to Europe and Asia Pacific

**カテゴリ:** What's New
**公開日:** 2026年8月19日
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/08/web-search-amazon-bedrock/)

---

## 要約

Amazon Bedrock AgentCore の Web Search ツールは、ランタイムドメインフィルタリングと公開日フィルタリング機能を新たにサポートし、ヨーロッパとアジア太平洋地域への展開を実現いたしました。この機能は、規制産業や研究ワークフローなど、情報ソースと鮮度に対する厳密な制御が必要なお客様に最適なソリューションとなります。

---

## このアップデートで何が変わったか

### 1. ドメインフィルタリング機能

- **ランタイムドメインフィルタリング**: エージェントが信頼できるソースに検索結果を絞り込み、リクエストごとに不要なドメインをブロック
- **ゲートウェイレベルのアローリスト機能**: 管理者が事前に許可ドメインを設定
- **ドメイン上限の拡張**: リストあたり最大100ドメインまでサポート（従来より大幅に拡張）

### 2. 公開日フィルタリング機能

- **時間枠指定検索**: 特定の時間枠内の結果に制限し、タイムリーで関連性の高いコンテンツのみが反映される
- **規制対応**: 古い情報や非推奨コンテンツを自動的に除外

### 3. 地域拡大

- **ヨーロッパ**: アイルランド（eu-west-1）でサービス提供開始
- **アジア太平洋**: 東京（ap-northeast-1）でサービス提供開始

### 4. パフォーマンス向上

- **セッション内の処理速度**: 25～35%高速化
- **認証キャッシング**: 不要なトークン取得を削減
- **プラットフォーム オーバーヘッド**: 地域により12～35%削減

## 対象ユーザー

### 1. 規制産業

- **金融機関**: コンプライアンス規制の最新情報に基づく意思決定支援
- **医療・ライフサイエンス**: 査読済み論文や認可情報への限定アクセス

### 2. 研究機関

- **学術組織**: 特定期間の査読済み論文からの自動知見抽出
- **企業研究部門**: 信頼できる情報源に限定した分析

### 3. エンタープライズ・システム

- **内容分析・監視**: 社内ドメイン + 承認外部サイトのハイブリッド検索
- **コンプライアンス監視**: 規制当局の公式発表のみを参照

## 利用のメリット

### ビジネス価値

1. **規制遵守**: ポリシーに基づく厳密な情報制御が可能
2. **精度向上**: ノイズの少ない高品質な検索結果を取得

### 技術的なメリット

1. **セキュリティ**: ゼロデータ流出、AWS 環境内での完全処理
2. **データレジデンシ**: 顧客の安全な環境内でのデータ保持
3. **管理の簡素化**: ゲートウェイレベルでの一元管理
4. **パフォーマンス**: キャッシングと最適化による高速処理

## 実装のポイント

### ドメインフィルタリングの設定

```json
{
  "gateway_allowlist": [
    "example.com",
    "research.org",
    "official.gov"
  ],
  "max_domains_per_list": 100
}
```

### 公開日フィルタリングの例

```json
{
  "published_after": "2026-08-01",
  "published_before": "2026-08-31"
}
```

## ユースケース実例

### ケース1: 金融分析エージェント

- **ドメイン制限**: 金融庁、証券取引所、信用格付機関のみを参照
- **日付制限**: 過去3ヶ月のニュース・公式発表を対象
- **効果**: コンプライアンスリスク低減、意思決定の信頼性向上

### ケース2: 医学文献検索エージェント

- **ドメイン制限**: PubMed、医学ジャーナルのみを参照
- **日付制限**: 直近1～2年の査読済み論文を対象
- **効果**: 最新で信頼できる医学情報の自動抽出

### ケース3: 規制監視エージェント

- **ドメイン制限**: 政府機関、業界団体の公式サイト
- **日付制限**: リアルタイムの最新規制情報
- **効果**: 規制変更の即座の検出と対応
