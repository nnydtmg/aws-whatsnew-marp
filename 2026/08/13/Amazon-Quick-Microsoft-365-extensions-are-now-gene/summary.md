# Amazon Quick がMicrosoft 365統合機能の一般提供を開始

Amazon Quick Microsoft 365 extensions are now generally available

**カテゴリ:** What's New
**公開日:** 2026-08-13
**元記事:** [Amazon Quick Microsoft 365 extensions are now generally available](https://aws.amazon.com/amazon-quick-microsoft-365-extensions-generally-available)

このページでは、AWS What's Newで発表された「Amazon Quick Microsoft 365 extensions are now generally available」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

AWSは、Amazon Quickエンタープライズアシスタント向けのMicrosoft 365拡張機能（Word、Excel、PowerPoint、Outlook）の一般提供を発表しました。ユーザーはすでに構成されたQuickインスタンスから、既存の権限やセキュリティポリシーを尊重しながらこれらの拡張機能にアクセスできます。Plus、Professional、Enterpriseプランのお客様は追加のライセンスなしでアクセス可能です。

## このアップデートで何が変わったか

Amazon Quickは、Word、Excel、PowerPoint、Outlookに統合される4つの新しいMicrosoft 365拡張機能を一般提供しました。これらの拡張機能は、ユーザーが既に時間を費やしている生産性アプリケーション内でAIアシスタントを利用できるようにします。

### 対応アプリケーション

- **Word**: 文書作成・編集支援
- **Excel**: データ分析・レポート作成
- **PowerPoint**: プレゼンテーション資料作成
- **Outlook**: メール・スケジュール管理

### 対応バージョン

- デスクトップ版
- Web版（ブラウザ版）

## 統合される機能

拡張機能は既存のQuick環境に接続し、以下を継承します：

- **ナレッジベース**: 組織内の知識データベース
- **データソース**: 接続済みのあらゆるデータソース
- **統合サービス**:
  - QuickSight ダッシュボード
  - Salesforce
  - Jira
  - Slack
  - SharePoint

## ライセンスと利用可能性

### 対象ユーザー

- **Amazon Quick Plus プラン**: 追加ライセンスなし
- **Amazon Quick Professional プラン**: 追加ライセンスなし
- **Amazon Quick Enterprise プラン**: 追加ライセンスなし
- **新規ユーザー**: 30日間の Enterprise トライアル経由で利用可能

## 主な利点

### ユーザー側

1. **ワークフロー統一**: Microsoft 365 を離れることなく AI 支援を利用
2. **セキュリティ維持**: 組織の権限・ポリシーが自動適用
3. **学習効率化**: 慣れた UI で直感的に利用可能
4. **コスト効率**: 追加ライセンスが不要

### 企業側

1. **採用率向上**: AI が既存ワークフロー内に組み込まれている
2. **統一管理**: アクセス制御を一元化できる
3. **生産性向上**: ビジネスユーザーが自力で分析・作成可能
4. **データ活用推進**: より多くのユーザーが企業データにアクセス

## 対応地域

アナウンスから、以下の地域で利用可能と考えられます：

- Asia Pacific (Sydney)
- Europe (Ireland)
- Asia Pacific (Tokyo)

- Europe (London)

## 導入方法

### 既存 Quick ユーザー

1. Amazon Quick ダウンロードページにアクセス
2. 拡張機能を選択してインストール
3. Microsoft 365 アプリから利用開始

### 管理者による一括デプロイ

1. Admin Center にアクセス
2. Microsoft 365 統合拡張機能をデプロイ対象に指定
3. ユーザーに自動配布
