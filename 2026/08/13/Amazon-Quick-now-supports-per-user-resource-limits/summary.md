# Amazon Quick のユーザー単位のリソース制限がサポート開始

Amazon Quick now supports per-user resource limits

**カテゴリ:** What's New
**公開日:** 2026-08-12T22:17:00

## 要約

Amazon Quick にユーザー単位のリソース制限機能が追加されました。これにより、企業は組織内の各ユーザーやグループのリソース利用を細かく管理でき、コスト最適化と利用状況の可視化が実現できます。

## このアップデートで何が変わったか

## 対象ユーザー

ユーザー単位のリソース制限により、Amazon Quick のフロー、スケジュール、インデックス容量などを、ユーザーやチーム単位で制御可能になります。これにより、誤用防止、コスト管理の強化、リソースの公平な配分が実現でき、エンタープライズ環境での運用が向上します。
