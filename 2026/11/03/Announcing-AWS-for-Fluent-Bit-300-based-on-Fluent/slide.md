# AWS for Fluent Bit 3.0.0 が Fluent Bit 4.1.1 ベースで提供開始

Announcing AWS for Fluent Bit 3.0.0 based on Fluent Bit 4.1.1

**What's New** | 2026-11-02T08:00:00

---

## 概要

- AWS for Fluent Bit 3.0.0は、Fluent Bit 4.1.1とAmazon Linux 2023を基盤に、OpenTelemetry対応ならびに性能およびセキュリティの向上を提供いたします。
- 本アップデートは、Amazon ECSおよびAmazon EKSをご利用のお客様に適しております。
