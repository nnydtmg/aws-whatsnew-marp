## 要約

AWS for Fluent Bit 3.0.0は、Fluent Bit 4.1.1とAmazon Linux 2023を基盤に、OpenTelemetry対応ならびに性能およびセキュリティの向上を提供いたします。本アップデートは、Amazon ECSおよびAmazon EKSをご利用のお客様に適しております。

## このアップデートで何が変わったか

- 新機能といたしまして、AWS for Fluent Bit 3.0.0はFluent Bit 4.1.1およびAmazon Linux 2023を基盤とし、ネイティブのOpenTelemetry対応を追加しております。
- JSON解析の高速化とTLSの最小バージョンおよび暗号の制御により、性能とセキュリティが向上しております。
- 本アップデートは、Amazon ECSおよびAmazon EKSをご利用のお客様に適しております。
