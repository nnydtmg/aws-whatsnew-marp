## 詳細

Amazon API Gateway が API Portal を発表しました。本機能は、Amazon API Gateway、Application Load Balancer、Amazon CloudFront の背後にある API と AI エンドポイントを、AWS Organizations 全体で検出・管理・文書化します。インストールやログ転送は不要で、AWS側のトラフィックログとサービス構成レコードから継続更新されるインベントリを構築します。検出された API は管理選択までシャドウ API となり、パブリックまたはプライベートとしてラベル付けし、MCP サーバー、A2A サーバー、LLM エンドポイントなどの AI エンドポイントを識別します。管理対象 API のセキュリティ体制を認証・スロットリング・AWS WAF 保護などのベストプラクティスと照らして評価し、ドキュメントポータルで公開できます。既存の API Gateway Portals は継続して利用でき、API Portal の Documentation Portals セクションから管理されます。32 の AWS リージョンで利用可能です。
