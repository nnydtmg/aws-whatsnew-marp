# AWS CloudFormationが206の新規リソースタイプをサポート

AWS CloudFormation makes resource coverage comprehensive with 206 new types

**What's New** | 2026-11-24T20:00:00

---

## 概要

- AWS CloudFormationが88サービスにわたる206の新規リソースタイプをサポートし、Cloud Control APIも対応を拡大しました。
- 安全でスケーラブルなインフラストラクチャ管理を標準化したいお客様に適した更新です。

## 変更内容・新機能

AWS CloudFormationは、88のサービスにわたる206の追加リソースタイプをサポートするようになりました。Amazon SageMaker Hub、Amazon Bedrock AgentCore PolicyEngine、Amazon EC2 Snapshotが新たに含まれます。これまでCloudFormationサポートがなかったプロビジョニング可能なAWSリソースの残りバックログを解消し、安全でスケーラブルなインフラストラクチャ管理ワークフローの標準化を支援します。新規のAI駆動内部フレームワークを活用してリソースタイプのオンボーディングコストを大幅に削減し、継続的なカバレッジ拡大を可能にしました。AWS Cloud Control APIはすべての新規リソースタイプをサポートし、99のサービスにわたる224の読み取り専用リソースタイプにも対応します。カバレッジは対象サービスが利用可能なすべてのAWSリージョンで利用できます。インフラストラクチャ管理を標準化したいお客様、既存AWSリソースを検索・検査したいお客様に適しています。
