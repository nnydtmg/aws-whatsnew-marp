# Amazon Route 53がプライベートエンドポイントのヘルスチェックをサポート

Amazon Route 53 now supports health checks for private endpoints

**カテゴリ:** What's New
**公開日:** 2026-11-19T19:50:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/11/route-53-private-endpoint-health-checks/)

このページでは、AWS What's Newで発表された「Amazon Route 53 now supports health checks for private endpoints」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

Amazon Route 53のプライベートエンドポイントヘルスチェックにより、非公開ワークロードでも数秒での自動DNSフェイルオーバーが可能になります。内部システムやハイブリッド環境を運用されるお客様に適した機能でございます。

## このアップデートで何が変わったか

Amazon Route 53は、プライベートエンドポイント向けヘルスチェックを新たに提供いたします。内部APIやデータベースなど、パブリックインターネットに触れないワークロードで、ネイティブなヘルス監視と自動DNSフェイルオーバーをご利用いただけます。IPアドレス、ドメイン、ポートを指定し、HTTP、HTTPS、TCPで到達可能なプライベートターゲットを監視できます。プライベートホストゾーンのDNSレコードに関連付け、正常なエンドポイントのみへ自動的にルーティングいたします。フェイルオーバーは数秒で完了するよう設計され、フルマネージドでインターネットへは公開されません。本機能は、従来カスタム制御ループを構築していたチームや、オンプレミスおよびハイブリッド環境のお客様に適しております。ビジネスクリティカルなプライベートワークロードを運用されるお客様にとって有益でございます。
