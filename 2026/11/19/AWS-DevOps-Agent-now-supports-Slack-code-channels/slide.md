# AWS DevOps AgentがSlackコードチャネルとMicrosoft Teams双方向会話をサポート

AWS DevOps Agent now supports Slack code channels and Microsoft Teams two-way conversations

**What's New** | 2026-11-18T08:00:00

## 概要

- AWS DevOps Agentは、オンコールエンジニアおよびDevOpsチームが既に協働している場所でインシデントを調査および解決できるよう、Slackの専用コードチャネルとMicrosoft Teamsの双方向会話を新たにサポートしました。

## 変更内容・新機能

Slack code channels give each investigation its own channel. Choose Open in code channel on an investigation card, and your team and the agent work on the investigation together in that channel. You can ask follow-up questions without @mentioning the agent. If you registered your Slack workspace before this launch, update your Slack permissions to use code channels.

新機能といたしまして、AWS DevOps Agentは専用のSlackコードチャネルとMicrosoft Teamsの双方向会話をサポートするようになりました。Slackでは調査ごとに専用チャネルが用意され、メンションなしでフォローアップの質問が可能です。M
