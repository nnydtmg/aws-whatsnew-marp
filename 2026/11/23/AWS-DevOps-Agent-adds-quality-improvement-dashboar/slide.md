# AWS DevOps Agent に品質改善ダッシュボードとツールが追加

AWS DevOps Agent adds quality improvement dashboards and tools

**What's New** | 2026-11-20T08:00:00

---

## 概要

- AWS DevOps Agentに品質ダッシュボードとリプレイ機能が追加され、インスタンスの品質を測定し改善できるようになりました。
- 品質とレイテンシーのダッシュボードで調査の根本原因発見率や所要時間を把握でき、グレーダーエージェントが調査を評価し人間評価と比較できます。
- リプレイ機能でスキルやメモリの変更をテストできます。
