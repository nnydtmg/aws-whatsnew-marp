# AWS Quick の Flows がチャットによる自動化構築をサポート

Build more capable automations through chat with Flows in AWS Quick

**What's New** | 2026-11-20T23:59:00

---

## 概要

- AWS QuickのFlowsは、会話だけで自動化を構築し、エージェント連携や検証、複数端末での実行に対応する新機能です。
- コーディング不要で業務を自動化したいチームや個人に適しています。

Users describe a process in chat, and Quick builds the flow, with no coding needed. Flows can now orchestrate agents, skills, and tools, with access to structured data, knowledge, and apps.
