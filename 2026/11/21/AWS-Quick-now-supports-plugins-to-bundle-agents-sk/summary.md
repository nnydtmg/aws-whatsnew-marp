# AWS Quickがプラグインをサポート、エージェントとスキルを一括導入

AWS Quick now supports plugins to bundle agents, skills, connectors and flows

**カテゴリ:** What's New
**公開日:** 2026-11-21T02:58:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-quick-plugins-bundle-agents-skills-connectors-flows/)

このページでは、AWS What's Newで発表された「AWS Quick now supports plugins to bundle agents, skills, connectors and flows」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

AWS Quickは、エージェント、スキル、コネクター、フローをまとめたプラグイン機能を新たに提供いたします。本アップデートは、業務に必要な機能を一括で導入したいユーザーおよびカスタムプラグインを作成したいビルダーの皆様に適しております。

## このアップデートで何が変わったか

- AWS Quickは、エージェント、スキル、コネクター、フローをバンドルするプラグインを新たにサポートいたします。
- プラグインにより、ユーザーはジョブに必要な機能をワンステップでインストールできます。
- ユーザーはカレンダーおよび会議アシスタントやセールス開発プラグインなどの公式プラグインを利用できます。
- ビルダーはチャットでジョブを説明するだけでカスタムプラグインを作成し、共有できます。
- 100以上のスキルとプラグインが生産性や財務、マーケティング、法務などの役割をカバーいたします。
- 本機能はAWS Quickが利用可能なすべてのリージョンでご利用いただけます。
- 本アップデートは、業務機能を一括導入したいユーザーに適しております。
- 本アップデートは、カスタムプラグインを作成したいビルダーやチームに適しております。
