# AWS Agent Registryが命名と公開発見機能の提供を開始

AWS Agent Registry now offers naming and public discovery capabilities

**カテゴリ:** What's New
**公開日:** 2026-11-20T08:00:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/11/agent-registry-naming-public-discovery/)

## 要約

AWS Agent Registryに、検証済みドメイン名を用いてエージェントを公開発見できる機能が追加されました。開発者およびネットワーク管理者はドメイン検証で所有権を証明し、エージェントを自社レジストリ・AWSアカウントの外へ公開できます。公開レコードは検証済みドメイン識別子に紐付くため接続前に出所を確認でき、AWS認証済みユーザーがセマンティック検索および語彙検索で検索可能です。本機能は追加料金なしで対応リージョンで利用できます。

## このアップデートで何が変わったか

- AWS Agent Registryは、検証済みドメイン名をエージェントやAIツールに付与する公開命名機能を提供します。
- 開発者およびネットワーク管理者は、ドメイン検証により所有権を証明し、エージェントを公開できます。
- 公開レコードは検証済みドメイン識別子に紐付くため、接続前に出所を確認できます。
- 公開後は、AWS認証済みユーザーがセマンティック検索および語彙検索で検索できます。
- 本機能は追加料金なしで、AWS Agent Registryが利用可能なすべてのリージョンでご利用いただけます。
- 本アップデートは、マルチエージェントシステムを構築する開発者およびネットワーク管理者に適しています。

## 詳細

AWS Agent Registry now offers public naming capabilities, making it easy to attach verified domain names to your agents and AI tools. Developers and network admins can perform domain verification checks to prove domain ownership, then associate the verified domain names with their agents to promote them for public visibility beyond their registry and AWS account. Previously, developers had to manually configure how agents discover and connect to one another, which added complexity to building multi-agent systems. With this launch, since the public agent records are anchored to a verified domain identity, you can confirm the source of an agent before connecting to it. Once published, agent records are searchable by any AWS-authenticated user using both semantic and lexical search. This capability is available at no additional charge at this time in all AWS Regions where AWS Agent Registry is available.
