# AWS Device FarmにTest Insightsが登場、テスト障害の迅速な把握と解決が可能に

Announcing Test Insights for AWS Device Farm

**What's New** | 2026-11-20T08:00:00

---

## 概要

- AWS Device FarmにTest Insightsが追加され、テスト障害の迅速な把握と解決が可能になりました。
- 本機能は追加費用なしでご利用いただけます。

## 変更内容・新機能

- 新機能は、AWS Device FarmのTest Insightsです。
- Appium、Espresso、およびXCUITestの複数デバイス実行向けに、テストの健全性と障害原因の詳細を提供します。
- 既存APIが強化メタデータ、スタックトレース、動画、所要時間、結果別件数を返すようになりました。
- 本アップデートは、モバイルおよびウェブアプリのテスターとAIエージェントに適しています。
- 障害調査の時間とトークンを削減し、トラブルシューティングスキルが修正を提案します。
- 追加費用なしで、Device Farm提供の全リージョンでご利用いただけます。
