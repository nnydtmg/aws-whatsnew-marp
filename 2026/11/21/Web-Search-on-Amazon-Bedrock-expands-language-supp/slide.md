# Amazon BedrockのWeb Searchが5言語対応と国別検索を拡充

Web Search on Amazon Bedrock expands language support and country-aware search

**What's New** | 2026-11-21T00:17:00

---

## 概要

- Amazon BedrockのWeb Searchが5つの新言語とオプションの国フィールドに対応いたしました。
- 多言語および多地域のユーザー向けエージェントにとって有益です。

## 変更内容・新機能

Amazon BedrockのWeb Searchは、スペイン語、フランス語、ドイツ語、イタリア語、日本語の5つの新しい言語と非米国英語を新たにサポートし、オプションの国フィールドによりISO 3166-1 alpha-2コードで特定国のソースに結果を偏らせることができます。本アップデートは、これらの言語のユーザーにサービスを提供するエージェントや、複数の国のユーザー向け、地域の規制・価格・公職者に関する質問に適しています。Web Search on Amazon Bedrockは、引用付きの最新Web情報でAIエージェントとアプリケーションをグラウンディングするツールです。今回、Amazon Bedrock AgentCoreおよびAmazon Bedrock上で、スペイン語、フランス語、ドイツ語、イタリア語、日本語の5つの新言語に加え、非米国英語もサポートしました。これらの言語のユーザー向けエージェントは、現地語のソースから結果を取得できます。また、オプションの国フィールドを導入し、ISO 3166-1 alpha-2国コード（例: JP、DE）を渡すだけで特定国のソースに結果を偏
