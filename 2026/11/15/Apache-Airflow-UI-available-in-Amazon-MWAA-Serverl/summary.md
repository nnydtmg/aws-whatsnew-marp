# Amazon MWAA ServerlessでApache Airflow UIが利用可能に

Apache Airflow UI available in Amazon MWAA Serverless

**カテゴリ:** What's New

## 要約

Amazon MWAA ServerlessでネイティブのApache Airflow UIがご利用いただけるようになりました。すでにAirflowに慣れているチームが使い慣れたインターフェースでワークフローをお取り扱いいただけます。

## このアップデートで何が変わったか

- 新機能は、Amazon MWAA ServerlessでネイティブのApache Airflow UIがご利用いただけるようになったことです。
- このUIではワークフローの閲覧、実行とタスクインスタンスの検査、タスクログの読み取り、ソースとバージョンの表示、実行の開始が可能です。
- UIは開いたIAMアイデンティティの権限を使用し読み取れるもののみを表示しますので、読み取り専用アクセスが可能です。
- このアップデートはすでにAirflowに慣れているチームにとって良いものです。
