# AWS Cloud WANがFlow Logsに対応、グローバルネットワークのIPトラフィックを一元可視化

AWS Cloud WAN now supports Flow Logs

**カテゴリ:** What's New
**公開日:** 2026-11-11T20:05:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-cloud-wan-flow-logs/)

このページでは、AWS What's Newで発表された「AWS Cloud WAN now supports Flow Logs」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

AWS Cloud WANがフローログに対応し、コアネットワーク全体のIPトラフィックを一元的に可視化できるようになりました。本機能はグローバルネットワークの運用を担当されるネットワーク管理者の皆様に有用です。

## このアップデートで何が変わったか

- AWS Cloud WANがフローログをサポートするようになり、グローバルネットワーク全体のIPトラフィックを中央で可視化できます。
- フローログはコアネットワーク全体、単一のコアネットワークエッジ、または個別のアタッチメントに対して有効化でき、Amazon CloudWatch Logs、Amazon S3、またはAmazon Data Firehoseに公開できます。
- 本アップデートは、複数のVPCやアカウント、リージョンにまたがるトラフィックを統合して確認したいネットワーク管理者およびコアネットワーク所有者に適しています。
- これまでネットワーク管理者は、複数のVPC・アカウント・リージョンからVPC Flow Logsを統合してグローバルネットワークのトラフィックを把握する必要があり、他チームにログアクセスを依存することも多かった。
- Cloud WAN Flow Logsは、VPC間、リージョン間、AWS Direct Connect / AWS Site-to-Site VPN / SD-WAN経由のオンプレミス経由トラフィックを一元的に可視化します。

## 詳細

- AWS Cloud WANがフローログをサポートするようになり、グローバルネットワーク全体のIPトラフィックを中央で可視化できます。
- フローログはコアネットワーク全体、単一のコアネットワークエッジ、または個別のアタッチメントに対して有効化でき、Amazon CloudWatch Logs、Amazon S3、またはAmazon Data Firehoseに公開できます。
- 本アップデートは、複数のVPCやアカウント、リージョンにまたがるトラフィックを統合して確認したいネットワーク管理者およびコアネットワーク所有者に適しています。
- これまでネットワーク管理者は、複数のVPC・アカウント・リージョンからVPC Flow Logsを統合してグローバルネットワークのトラフィックを把握する必要があり、他チームにログアクセスを依存することも多かった。
- Cloud WAN Flow Logsは、VPC間、リージョン間、AWS Direct Connect / AWS Site-to-Site VPN / SD-WAN経由のオンプレミス経由トラフィックを一元的に可視化します。
- フローログレコードにはIPアドレス、ポート、プロトコル、トラフィック量、パケットロスカウンタに加え、セグメント・リージョン・サービス挿入ホップ・アタッチメント情報などのCloud WANメタデータが含まれます。
- 接続性・パフォーマンスのトラブルシューティング、履歴帯域幅トレンドに基づくキャパシティ計画、異常トラフィックの検出、セキュリティ・コンプライアンス向けの記録保持に活用できます。
- Cloud WAN側のFlow Logs利用料金は無料で、送信先（CloudWatch Logs / S3 / Data Firehose）の標準料金のみが発生します。
- AWS Cloud WANが利用可能なすべてのリージョンで利用可能で、AWS Management Console、AWS CLI、APIから開始できます。
