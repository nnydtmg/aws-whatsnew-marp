# AWS DevOps Agent がコミュニティ・パートナー向けツールリポジトリを追加

AWS DevOps Agent adds community and partner tools repository

**What's New** | 2026-11-20T08:00:00

---

## 概要

- AWS DevOps Agentに、スキルやコネクタなどを共有・活用できるコミュニティおよびパートナー向けツールリポジトリが追加されました。
- 本アップデートは、調査品質の向上と運用コンテキストの拡大を求めるお客様に適しています。

## 変更内容・新機能

AWS DevOps Agentにコミュニティおよびパートナー向けツールリポジトリが追加されました。スキル、MCPサーバー、コネクタ、カスタムエージェントを共有および活用できるようになりました。AWSがキュレーションしたオープンソースリポジトリから、品質管理されたすぐに使えるツールをインポートできます。本アップデートは、調査品質の向上と運用コンテキストの拡大を望むAWS DevOps Agentのお客様に適しています。サードパーティのMCPサーバーへの接続を簡素化したいユーザーおよびパートナーにも適しています。
