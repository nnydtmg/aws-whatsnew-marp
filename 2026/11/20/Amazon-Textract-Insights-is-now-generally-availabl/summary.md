# Amazon Textract Insights が一般提供開始、単一リクエストで文書理解を実現

Amazon Textract Insights is now generally available

**カテゴリ:** What's New
**公開日:** 2026-11-20T08:00:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/11/textract-insights-ga/)

このページでは、AWS What's Newで発表された「Amazon Textract Insights is now generally available」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

Amazon Textract Insightsが米国東部（バージニア北部）および米国西部（オレゴン）リージョンで一般提供開始となり、単一の非同期リクエストで文書理解を実現します。保険請求や税務パケットなどの混在文書を処理されるお客様に適した機能です。

## このアップデートで何が変わったか

- 新機能はAmazon Textract Insightsであり、Amazon Textractの新しい生成AI機能として一般提供が開始されました。
- 本機能は単一の非同期リクエストで文書の分割、分類、および構造化データの抽出を行います。
- お客様はブループリントで必要なフィールドを自然言語により定義でき、AIモデルの学習は不要です。
- 各抽出値の信頼度スコアとページ上の位置を返し、Markdown、HTML、プレーンテキストの出力にも対応します。
- 文書要約、図のキャプション生成、個人識別情報の検出とマスキングもご利用いただけます。
- 本アップデートは保険請求、税務パケット、オンボーディングパッケージなど複数文書が混在したスキャンを処理されるお客様に適しています。
- 検索拡張生成アプリケーションを構築されるお客様にも有用です。
