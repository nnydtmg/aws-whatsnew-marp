# AWS DevOps Agentが新しいチャット機能を追加

AWS DevOps Agent adds new chat capabilities

**カテゴリ:** What's New
**公開日:** 2026-11-20T08:00:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/11/devops-agent-new-chat-capabilities/)

## 要約

AWS DevOps Agentはチャット機能を拡張し、開発者および運用チームが好みのチャットインターフェースからワークフローを自動化できるようになりました。MCPクライアント（Kiro、Claude Code）、Slack、Microsoft Teamsに対応し、GitHub / GitLab / Azure DevOps / ServiceNow / PagerDuty のMCPツールによる指示型操作、インシデントごとのSlackコードチャンネル自動作成、Teams双方向チャット、サンドボックスでのスクリプト実行、チャットの名前変更・アーカイブが可能になりました。

## このアップデートで何が変わったか

- AWS DevOps Agentは、KiroやClaude CodeなどのMCPクライアント、ならびにSlackおよびMicrosoft Teamsにわたる新しいチャット機能を追加しました。
- MCPサポートにより、GitHub、GitLab、Azure DevOps、ServiceNow、PagerDutyのMCPツールを用いた指示型チャット操作が可能になりました。
- インシデントごとのSlackコードチャンネルの自動作成と、Microsoft Teams内での双方向チャットが追加されました。
- コンピュートサンドボックスでのスクリプト実行とネットワークアクセス、ならびに全対応プラットフォームでのチャットの名前変更およびアーカイブが可能になりました。
- 本アップデートは、開発者および運用チームに適しています。
