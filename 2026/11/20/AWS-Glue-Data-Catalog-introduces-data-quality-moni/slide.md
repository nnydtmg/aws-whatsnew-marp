# AWS Glue Data Catalogがカタログとデータベースのデータ品質監視を発表

AWS Glue Data Catalog introduces data quality monitoring for catalogs and databases

**What's New** | 2026-11-20T19:00:00

---

## 概要

- AWS Glue Data Catalogに、単一の設定でカタログおよびデータベースのデータ品質を監視する新機能が導入されました。
- テーブルごとの設定なしに品質問題を検出し、下流への不良データ到達防止に役立ちます。
