## 詳細

AWS Partners can now expedite Migration Acceleration Program (MAP) deals, from qualification to incentive payout, with an end-to-end agentic workflow in AWS Transform. Partners can manage the full MAP lifecycle without leaving AWS Transform, including deal qualification, funding approvals, agreement execution, migration planning and execution, resource tagging, and incentive disbursement. Previously, Partners had to switch between separate systems for opportunity discovery, assessments, deal qualification, funding approvals, agreement execution, resource tagging, and incentive disbursement. This fragmentation, along with manual handoffs between steps, led to longer qualification cycles. Now, with the agentic MAP experience in AWS Transform, Partners connect their AWS Partner Central account and invite customers into the same engagement. Partners start by scoping customer environments with the built-in agentic discovery tool, or by importing data from RVTools or AWS-validated ISV tools listed in AWS Marketplace. AWS Transform then combines this discovery data with opportunity details from APN Customer Engagements (ACE) to automatically qualify Partner-initiated opportunities in a guided flow, so Partners get eligibility decisions sooner and close deals faster. As the migration progresses, MAP resource tags are applied automatically, and Partner cash and customer credits are disbursed based on actual usage data. Throughout, customers get shared, real-time visibility into migration projects alongside their Partner. AWS Transform with integrated MAP is now available in all AWS Regions where AWS Transform is supported.
