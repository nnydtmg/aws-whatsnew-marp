# AWS Control Towerが既存のAmazon S3バケットでのログ配信をサポート

AWS Control Tower now supports existing Amazon S3 bucket for log delivery

**カテゴリ:** What's New
**公開日:** 2026-11-18T08:00:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/11/control-tower-existing-s3-log-bucket/)

このページでは、AWS What's Newで発表された「AWS Control Tower now supports existing Amazon S3 bucket for log delivery」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

AWS Control Towerは既存のAmazon S3バケットをログ配信に利用できる機能を追加いたしました。この更新は、ログインフラストラクチャを完全に制御したいお客様に適しております。

## このアップデートで何が変わったか

- AWS Control Towerは、ランディングゾーン内の既存のAmazon S3バケットをAWS ConfigおよびAWS CloudTrailのログ保存に使用できるようになりました。
- お客様はバケットポリシー、ライフサイクルルール、ログインフラストラクチャを完全に制御できます。
- 自己管理バケットとAWS Control Tower管理バケットをいつでも切り替えられ、バケットはランディングゾーンの更新時にも保持されます。
- この更新は、すでに管理しているAmazon S3バケットに集中ログを統合したいお客様に適しております。
