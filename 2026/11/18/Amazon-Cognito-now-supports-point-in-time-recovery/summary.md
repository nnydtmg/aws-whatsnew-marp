# Amazon Cognitoがポイントインタイムリカバリをサポート

Amazon Cognito now supports point-in-time recovery

**カテゴリ:** What's New
**公開日:** 2026-11-18T17:00:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/11/cognito-point-in-time-recovery/)

## 要約

Amazon Cognitoにポイントインタイムリカバリ（PITR）が追加され、ユーザープールのユーザーデータを以前の時点へ復元できるようになりました。EssentialsおよびPlusプランのお客様に追加料金なしで自動的に提供されます。復旧ウィンドウはEssentialsで1日、Plusで14日です。

## このアップデートで何が変わったか

【新機能】
- 復旧ポイントを選択し、ユーザー、グループ、MFA設定、パスキーの作成・更新・削除数をプレビューしたうえで、復旧を開始またはキャンセル可能
- 復旧されたユーザーは識別子、パスワード、MFA設定、パスキーを保持するため、資格情報をリセットせずにサインイン可能
- スクリプトによる誤削除・誤変更時に、実行直前の状態へ復元可能
- 同じユーザープール内でインプレース復元（ID・ARN・設定は維持）

【復旧ウィンドウ】
- Lite: 非対応
- Essentials: 最大1日
- Plus: 最大14日
- 追加料金なしで自動有効

## 詳細

Amazon Cognito now supports point-in-time recovery (PITR)。ユーザープールのユーザーデータを以前の時点に復元できます。

【新機能】
- 復旧ポイントを選択し、ユーザー、グループ、MFA設定、パスキーの作成・更新・削除数をプレビューしたうえで、復旧を開始またはキャンセル可能
- 復旧されたユーザーは識別子、パスワード、MFA設定、パスキーを保持するため、資格情報をリセットせずにサインイン可能
- スクリプトによる誤削除・誤変更時に、実行直前の状態へ復元可能
- 同じユーザープール内でインプレース復元（ID・ARN・設定は維持）

【復旧ウィンドウ】
- Lite: 非対応
- Essentials: 最大1日
- Plus: 最大14日
- 追加料金なしで自動有効

【復元対象】
- ユーザープロファイル（標準・カスタム属性）
- グループとグループ所属
- 再作成ユーザーのパスワード
- MFA設定（TOTP含む）
- パスキー

【復元されないもの】
- ユーザープール設定、アプリクライアント、IdP、ドメイン、暗号化設定、トークン、記憶デバイス

【復旧中の動作】
- 書き込み操作は一時停止
- サインイン・読み取りは継続
- プレビュー生成後24時間以内に開始またはキャンセルが必要

【制限】
- ユーザープールあたり同時に1つの復旧
- 24時間に1回の完了、最大3回の開始
- 30日間に最大10回の開始

【利用方法】
- AWS Management Console、Amazon Cognito API、AWS CLI、AWS SDKs
- Cognitoが利用可能なすべてのAWSリージョンで利用可能

【ユースケース】
- 独自のエクスポート・復元プロセスを構築・維持していたお客様
- 誤ってユーザーを削除・変更してしまった場合に迅速に復元したいお客様
- 管理スクリプト、アプリのバグ、無断な操作によるユーザーデータの捕滅

【以前の課題】
- 独自のエクスポート・復元プロセスを構築・維持する必要があった
- 復元後のユーザーは新しい識別子を付与され、パスワードのリセットが必要だった
