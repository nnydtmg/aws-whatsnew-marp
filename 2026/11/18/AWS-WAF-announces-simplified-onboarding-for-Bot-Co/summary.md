# AWS WAF が Bot Control のターゲット保護向け簡素化オンボーディングを発表

AWS WAF announces simplified onboarding for Bot Control targeted protection

**カテゴリ:** What's New
**公開日:** 2026-11-17T08:00:00

## 要約

AWS WAFはBot Controlのターゲット保護向けに簡素化されたオンボーディングを発表いたしました。Amazon CloudFrontをご利用のお客様が、推奨設定で高度なボット対策を容易に導入できるようになります。

## このアップデートで何が変わったか

-新機能は、Bot Controlのターゲット検査レベルにおける簡素化されたコンソール体験です。
- 「Targeted bot control」という単一の設定により、Amazon CloudFrontディストリビューションにAWSが推奨する構成のターゲット保護を有効にできます。
- ボット信頼レベルとLATESTバージョンが追加され、ラベルマッチルールの記述やアプリケーションコードの変更なしで、高度でAI搭載のボットから保護できます。
- この更新は、Amazon CloudFrontをご利用のお客様に適しております。
- 高度でAI搭載のボットからアプリケーションを保護したいお客様に適しております。
