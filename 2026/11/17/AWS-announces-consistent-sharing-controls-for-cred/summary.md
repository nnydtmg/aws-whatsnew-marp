# AWSがクレジット、Savings Plans、RIの一貫した共有制御を発表

AWS announces consistent sharing controls for credits, Savings Plans, and Reserved Instances

## 要約

AWS Billing and Cost Managementは、クレジット、Savings Plans、リザーブドインスタンスの組織内共有を細かく制御する機能を提供します。助成金、規制上の義務、複数エンティティ構造を持つ組織における手動チャージバック調整の自動化に適しています。

## このアップデートで何が変わったか

新機能は、クレジット、Savings Plans、およびリザーブドインスタンスの組織内共有を対称的かつ細かく制御できる機能です。デフォルトの共有設定をすべてのコスト削減特典に自動適用し、個別の特典では上書きできます。共有設定はCost Categoriesを使用し、2026年11月17日よりすべてのAWSリージョンで追加料金なしで利用できます。本アップデートは、助成金、規制上の義務、または複数エンティティ構造を持つ組織に適しており、従来の手動チャージバック調整を自動化できます。
