# AWS Security HubがGCPの統合セキュリティ管理に対応

AWS Security Hub extends unified security management to Google Cloud Platform

**What's New** | 2026-11-17T08:00:00

---

## 概要

- AWS Security HubがGCPリソースの監視を開始し、AWSとGCP環境のセキュリティ管理を統一いたします。
- これにより、両クラウドを利用するお客様が一つのコンソールでリスク対応を実施できるようになります。

## 変更内容・新機能

- AWS Security Hubは、Google Cloud Platformのリソースを監視する新機能を提供いたします。
- これにより、AWSとGCPの両環境にわたるリスク分析、セキュリティ態勢管理、脆弱性管理が統一されます。
- GCP仮想マシン、コンテナイメージ、Cloud Run関数、アイデンティティを自動発見し、誤設定や脆弱性を評価いたします。
- CISベンチマークに基づくチェックとEventBridgeによる自動対応が可能になります。
- 本アップデートは、AWSとGCPでワークロードを運用するお客様に適しております。
- セキュリティチームが一つのコンソールで優先順位付けと対応を行えるようになります。
