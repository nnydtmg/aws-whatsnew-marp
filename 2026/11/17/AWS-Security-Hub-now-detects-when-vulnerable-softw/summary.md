# AWS Security HubがEC2上で実行中の脆弱ソフトウェアを検出可能に

AWS Security Hub now detects when vulnerable software is running on Amazon EC2 instances

**カテゴリ:** What's New
**公開日:** 2026-11-16T08:00:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/11/security-hub-detects-vulnerable-software/)

このページでは、AWS What's Newで発表された「AWS Security Hub now detects when vulnerable software is running on Amazon EC2 instances」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

AWS Security Hubは実行中の脆弱なソフトウェアを検出し、重大度を高く評価することで、セキュリティチームが最大のリスクに集中できるようになりました。本機能はEssentialsプランで追加料金なしでご利用いただけます。

## このアップデートで何が変わったか

- AWS Security Hubは、既知の脆弱性を持つソフトウェアがAmazon EC2インスタンス上で実行中であることを検出する新機能を提供いたします。
- 該当するエクスポージャー検出結果には新しい特性が追加され、より高い重大度評価が付与されます。
- GuardDuty Runtime MonitoringとInspector VM Scannerのデータを相関させて検出いたします。
- 本機能はSecurity Hub Essentialsプランで追加料金なしでご利用いただけます。
- 数千のインスタンスを管理するセキュリティチームが、実際のランタイムリスクに基づいて対応を優先するのに役立ちます。
