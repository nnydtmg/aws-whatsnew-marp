# Claude Opus 5が Amazon Bedrock で利用開始

Claude Opus 5 is now available on AWS

**What's New | 発表日: 2026-07-24**

---

## 概要

### Claude Opus 5 の3つの主要特徴

- **高度なコーディング機能**: 経験豊富なエンジニアレベルでのコード理解と操作
- **長時間実行エージェント**: 数時間から一晩中の連続実行に対応
- **複雑な分析能力**: 長いドキュメント処理での深い推論と高精度

### アクセス方法

- **Amazon Bedrock**: ZDR デフォルト有効、Guardrails・Knowledge Bases 統合
- **Claude Platform on AWS**: AWS コンソール統合、Anthropic ネイティブ体験

### 1. 高度なコーディング機能

- **コードベース理解**: エンジニアレベルでのコード分析

- **自動回復**: エラーからの自己修復

### 3. 複雑な分析

- **深い推論**: 長いドキュメント処理での高精度
- **エンタープライズ対応**: ドキュメント重視業務での高効果
- **精度向上**: 複雑分析タスクでの性能改善

## AWS での提供方法

### Amazon Bedrock

- **データ無保持（ZDR）**: デフォルト有効でデータガバナンス対応
- **統合機能**: Guardrails、Knowledge Bases への直接アクセス
- **セキュリティ**: エンタープライズグレード、Ops 最高レベル

### Claude Platform on AWS

- **統合環境**: AWS コンソール経由のアクセス
- **ネイティブ体験**: Anthropic 提供のプラットフォーム
- **ZDR 対応**: リクエストに応じてサポート
- **API 互換性**: Anthropic 直接連携と同じ API・機能
