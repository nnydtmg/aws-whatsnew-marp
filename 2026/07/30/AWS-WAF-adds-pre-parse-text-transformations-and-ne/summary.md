# AWS WAFがプリパーステキスト変換と新しいテキスト変換を追加

AWS WAF adds pre-parse text transformations and new text transformations

## 要約

AWS WAFは、クエリ引数のプリパーステキスト変換と10個の新しいテキスト変換を追加し、リクエストコンテンツの正規化を強化しました。これにより、HTTPパラメータ汚染やパーサー差分回避などのセキュリティギャップを閉じることができます。

## このアップデートで何が変わったか

- AWS WAFは、クエリ引数に対するプリパーステキスト変換と10個の新しいテキスト変換を追加しました。

- 各新しい変換は10 WCUを消費し、標準のAWS WAF料金を超える追加料金はかかりません。

## 対象ユーザー

- セキュリティ要件が厳しく、HTTPパラメータ汚染やパーサー差分回避攻撃から保護する必要があるユーザーに有益です。

## 詳細

- AWS WAFは、クエリ引数に対するプリパーステキスト変換と10個の新しいテキスト変換を追加しました。

- プリパーステキスト変換は、AWS WAFがキー値ペアに解析する前に生のクエリ文字列を正規化し、HTTPパラメータ汚染とパーサー差分回避のギャップを閉じます。

- URLデコード、重複クエリ引数をコンマで結合、セミコロンをアンパサンドに置換を含む最大10個の変換をチェーンできます。

- 新しいテキスト変換には、大文字、トリム、空白削除、SHA256などの業界標準オプションが含まれています。

- Amazon脅威研究チームが開発したOSに対応したコマンドラインおよびJavaScript デコード機能が提供されます。

- 各新しい変換は10 WCUを消費し、標準のAWS WAF料金を超える追加料金はかかりません。

- この機能はすべてのAWSリージョンで利用可能です。

- このアップデートは、リクエストコンテンツを正規化し、AWS WAFがアプリケーションと同じ方法でリクエストを検査することを望む組織に適しています。

- セキュリティ要件が厳しく、HTTPパラメータ汚染やパーサー差分回避攻撃から保護する必要があるユーザーに有益です。
