# Amazon CloudFrontの動的画像変換に4つの新機能が追加

Dynamic Image Transformation for Amazon CloudFront adds four new features

**What's New** | 2026-09-08T14:32:00

---

## 概要

- Dynamic Image Transformation for Amazon CloudFrontに4つの新機能が追加され、強化スマートクロッピング、自動画像最適化、変換プレイグラウンド、およびECSとLambdaの機能パリティが利用可能になりました。
- 本アップデートは、あらゆるデバイス向けに最適化された画像配信を行うお客様に適しています。

## 変更内容・新機能

- 新機能は、Dynamic Image Transformation for Amazon CloudFrontに追加された4つの機能です。
- 強化されたスマートクロッピングにより、カスタムラベル検出と高度な構図制御で製品、テキスト、ロゴ、カスタムオブジェクトを切り抜き画像内に保持できます。
- 強化された自動画像最適化により、スマートフォンからスマートTVまで適切なサイズの画像を配信できます。
- インタラクティブな画像変換プレイグラウンドで変換のテストと検証が可能です。
- ECSとLambdaアーキテクチャ間で完全な機能パリティが実現されました。
- 本アップデートは、多様なデバイスへ最適化画像を配信したいお客様に適しています。
- 重要なオブジェクトを保持したクロッピングや変換検証を必要とするお客様にも有用です。
