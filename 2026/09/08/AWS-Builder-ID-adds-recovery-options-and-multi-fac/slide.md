# AWS Builder IDがリカバリーオプションとサードパーティログイン向けMFAを追加

AWS Builder ID adds recovery options and multi-factor authentication for third-party logins

**What's New** | 2026-09-08T08:00:00

---

## 概要

- AWS Builder IDにリカバリーオプションとサードパーティログイン向けのMFAが追加されました。
- これにより、ユーザーはセルフサービスでアカウントを回復し、より強固な保護を享受できます。

## 変更内容・新機能

AWS Builder ID（AWS Builder Center、AWS Training and Certification、Amazon Q、Kiro などの AWS アプリケーションにアクセスするための個人プロファイル）に、プロファイルの保護と回復のための新しい方法が追加されました。リカバリーメールの追加とセルフサービスによるアカウント回復オプションが提供されます。パスワードを忘れた場合は、プライマリまたはリカバリーメールに送信されるリンクでリセットできます。MFAデバイスを紛失した場合は、プライマリとリカバリーの両方のメールを確認することでアクセスを回復できます。Google、Apple、GitHub、Amazon などのサードパーティログインに対してMFAデバイスを直接登録できるようになり、これまでメールとパスワードユーザーのみに提供されていた強力なアカウント保護が利用可能になりました。サードパーティアカウントへのアクセスを失った場合は、サインイン方法をメールアドレスとパスワードに永続的に切り替えることもできます。このアップデートは、AWS Builder IDをご利用のお
