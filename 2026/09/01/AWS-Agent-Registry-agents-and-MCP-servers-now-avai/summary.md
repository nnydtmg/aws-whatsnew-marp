# AWS Agent Registry のエージェントと MCP サーバーが Amazon Quick で利用可能に

AWS Agent Registry agents and MCP servers now available in Amazon Quick

**カテゴリ:** What's New
**公開日:** 2026-08-31T21:05:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/08/aws-agent-registry-agents-mcp-servers-quick/)

このページでは、AWS What's Newで発表された「AWS Agent Registry agents and MCP servers now available in Amazon Quick」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

Amazon QuickがAWS Agent Registryとの統合を発表し、技術チームが構築したエージェントやMCPサーバーをビジネスユーザーが簡単に利用できるようになりました。

## このアップデートで何が変わったか

- 新機能は、Amazon QuickとAWS Agent Registryの統合でございます。
- ユーザーは組織のAWS Agent RegistryからMCPサーバーとエージェントをAmazon Quick内で検索および閲覧できます。
- 接続詳細はレジストリから自動入力され、数クリックで有効化できます。
- 有効化したリソースはチャット、エージェント、アプリ、フロー、ディープリサーチでチームと共有できます。
- 本アップデートは、Amazon Bedrock AgentCoreでエージェントを構築する技術チームに適しております。
- また、Amazon Quickで作業するビジネスユーザーおよび手動設定の重複を削減したい組織に適しております。

## 対象ユーザー

### 技術チーム
- Amazon Bedrock AgentCoreでエージェントを構築する開発者
- MCP サーバーを開発・管理するエンジニア
- 組織内のAI資産を管理する責任者

### ビジネスユーザー
- Amazon Quick で日常的に作業するユーザー
- エージェントやツールを活用したい業務ユーザー

### 組織
- 手動設定の重複を削減したい企業
- AI資産の一元管理を実現したい組織

## 詳細

### 主な機能

1. **統合されたディスカバリー**
   - Amazon Quick内からAWS Agent Registryにアクセス
   - エージェントとMCPサーバーを検索・閲覧可能

2. **自動設定**
   - 接続詳細がレジストリから自動入力
   - 数クリックで有効化可能

3. **リソース共有**
   - 有効化したリソースをチーム全体で共有
   - チャット、エージェント、アプリ、フロー、ディープリサーチで利用可能

### メリット

- **効率化**: 手動設定の重複を削減
- **可視化**: 組織内のエージェント・ツール資産を一元管理
- **アクセス性**: ビジネスユーザーが簡単に利用可能
- **スケーラビリティ**: 組織全体での展開が容易
