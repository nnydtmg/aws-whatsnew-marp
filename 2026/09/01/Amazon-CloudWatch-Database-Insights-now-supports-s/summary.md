# Amazon CloudWatch Database Insights がセルフマネージド PostgreSQL に対応

Amazon CloudWatch Database Insights now supports self-managed PostgreSQL

**カテゴリ:** What's New
**公開日:** 2026-09-01
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/08/database-insights-self-managed-postgresql/)

このページでは、AWS What's Newで発表された「Amazon CloudWatch Database Insights now supports self-managed PostgreSQL」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

Amazon CloudWatch Database InsightsがセルフマネージドPostgreSQLのサポートを開始し、EC2上のデータベースをRDSやAuroraと統一的に監視できるようになりました。

## このアップデートで何が変わったか

- 新機能は、Amazon CloudWatch Database InsightsがセルフマネージドPostgreSQLデータベースをサポートすることです。
- Amazon EC2上のインスタンスをAmazon RDSおよびAmazon Auroraと併せて単一のコンソールで監視できます。
- CloudWatch agentを使用してセルフマネージドPostgreSQLインスタンスから健全性とパフォーマンスデータを収集します。
- データベースロード、ウェイトイベント分析、クエリレベルの統計情報、ホストメトリクスなどのライブパフォーマンスデータが表示されます。
- この更新は、データベースフリート全体を統合監視したいお客様に適しております。
