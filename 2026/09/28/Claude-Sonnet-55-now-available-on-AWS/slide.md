# Claude Sonnet 5.5 が AWS で利用可能に

Claude Sonnet 5.5 now available on AWS

**What's New** | 2026-09-28T15:00:00

---

## 概要

- AWSでClaude Sonnet 5.5が提供開始され、コーディングとナレッジワークが強化されたよりスマートで効率的なモデルです。
- すでにSonnetを利用しているチームに適した自然なアップグレードとなります。

## 変更内容・新機能

- 新機能は、AWSで提供開始されたClaude Sonnet 5.5です。
- 本モデルはSonnet 5からのアップグレードであり、よりスマートで効率的です。
- コーディングとナレッジワークにおいて明確に進化し、ほとんどの作業でタスクあたりのコストが低く、より高速です。
- スコープが明確なコーディングタスクの完了や、同一セッションでの機能構築・修正、要件に対する出力検証が強化されています。
- 1枚資料、図表、サマリースライド、ドキュメント編集、スプレッドシートのクリーンアップなど、共有可能な成果物を作成できます。
- 利用方法はAmazon BedrockとClaude Platform on AWSの2つです。
- 本アップデートは、すでにSonnet上で構築しているチームに適しています。
- コーディングやナレッジワークを行うお客様に適しています。
- データをAWSインフラ内に保持し、リージョンデータレジデンシーを求めるお客様にはAmazon Bedrockが適しています。
- Anthropicのネイティブなプラットフォーム体験をAWSの請求および認証と統合して利用し
