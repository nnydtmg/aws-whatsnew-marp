# AWS End User MessagingとAmazon SESがMCP Server向けAIスキルを提供

AWS End User Messaging and Amazon SES now offer AI agent skills for the AWS MCP Server

**What's New** | 2026-09-25T07:00:00

---

## 概要

- AWS End User MessagingおよびAmazon SESがAWS MCP Server向けAIエージェントスキルを公開し、開発者は自然言語でメッセージング作業を完了できるようになりました。
- 本機能は、ドキュメント検索やコンソール操作を省略したい開発者に適しております。

## 変更内容・新機能

AWS End User MessagingとAmazon SESが、AWS MCP Server向けのAIエージェントスキルを新たに提供開始しました。開発者は自然言語でAIコーディングエージェントに依頼するだけで、メッセージの構築と送信が可能になります。以前は複数のドキュメントページやマネジメントコンソール画面を行き来してメッセージング作業を完了する必要がありましたが、各スキルが検証済みのステップバイステップガイドをエージェントに提供します。対応タスクには送信IDの検証、ブランド付きRCSエージェントの構築、本番メールの送信などが含まれます。Claude Code、Codex、Cursor、Kiroなどの主要なAIコーディングエージェントと統合できます。利用にはまずAWS MCP Serverをエージェントに接続し、使用したいチャネルのスキルを追加します。
