# Claude Opus 5.5 が AWS で利用可能に

Claude Opus 5.5 is now available on AWS

**What's New** | 2026-09-22T15:00:00

---

## 概要

- AWSでClaude Opus 5.5が利用可能になりました。
- Anthropicの最も有能なOpusモデルでありClaude 5.5ファミリーの最初のモデルです。
- 長時間のコーディングやナレッジワークを処理し、実施内容と必要な対応を明確に報告するより良いコラボレーターです。
- Claude Opus 5より少ないトークン数と低い単価でタスクを完了し、Amazon BedrockまたはClaude Platform on AWSからアクセスできます。

## 変更内容・新機能

AWSでClaude Opus 5.5が利用可能になりました。Anthropicの最も有能なOpusモデルでありClaude 5.5ファミリーの最初のモデルです。長時間のコーディングやナレッジワークを処理し、実施内容と必要な対応を明確に報告するより良いコラボレーターです。Claude Opus 5より少ないトークン数と低い単価でタスクを完了し、Amazon BedrockまたはClaude Platform on AWSからアクセスできます。

---

## 効果・メリット

- AWS now offers Claude Opus 5.5, Anthropic's most capable Opus model yet and the first of the Claude 5.5 model family. It is a better collaborator that handles long-running coding and knowledge work, reporting back clearly on what it did, what it found, and what it needs next. According to Anthropic, Claude Opus 5.5 completes tasks using fewer tokens than Claude Opus 5, at a lower price per token
