# AWS Glue Data Qualityが生成AIでコンテキスト固有のルール推奨を数秒で提供

AWS Glue Data Quality delivers context-specific rule recommendations in seconds

**What's New** | 2026-09-22T08:00:00

---

## 概要

- AWS Glue Data Qualityの新しいAdvancedモードは、生成AIを活用して数秒でビジネス関連のデータ品質ルールを全カラムに推奨します。
- 手動設定なしで生データから信頼できるデータへの移行をパイプライン作成時に加速します。
