## 要約

AWS Glue Data Qualityの新しいAdvancedモードは、生成AIを活用して数秒でビジネス関連のデータ品質ルールを全カラムに推奨します。手動設定なしで生データから信頼できるデータへの移行をパイプライン作成時に加速します。

## このアップデートで何が変わったか

AWS Glue Data Qualityは、AWS Glue Data Catalogのテーブルに対するデータ品質チェックの確立時間を短縮し、数秒でデータ品質ルールを生成できるようになりました。全カラムをカバーするすぐに使えるルールセットを手動設定なしで取得でき、パイプライン作成時に生データから信頼できるデータへより速く移行できます。これはルール推奨の新しいAdvancedモードによって提供されます。AWS Glue Data Qualityは生成AIを使用してデータの背後にある意図を検出し、データの使われ方を反映したビジネス関連のルールを提案します。このAdvancedモードを使用して、新たにオンボードしたデータセットのルールをブートストラップしたり、大規模なデータレイク全体にベースラインチェックを手書きせずに確立したりできます。推奨ルールを確認し、必要に応じて調整して、ルールセットとして保存すればすぐにモニタリングを開始できます。Advancedモードは以下のAWSリージョンで利用可能です: アジアパシフィック（メルボルン、大阪、シドニー、東京）、カナダ（中部）、欧州（フランクフ
