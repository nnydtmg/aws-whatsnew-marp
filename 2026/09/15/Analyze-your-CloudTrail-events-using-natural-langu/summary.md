# Amazon Q ConsoleでCloudTrailイベントを自然言語で分析可能に

Analyze your CloudTrail events using natural language in Amazon Q Console

**カテゴリ:** What's New
**公開日:** 2026-09-15T16:54:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/09/cloudtrail-amazon-q-console/)

このページでは、AWS What's Newで発表された「Analyze your CloudTrail events using natural language in Amazon Q Console」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

AWS CloudTrailがAmazon Qコンソールと統合され、自然言語でアカウントアクティビティを調査できるようになりました。本機能はセキュリティ監査や運用トラブルシューティングを行うお客様に適しています。

## このアップデートで何が変わったか

新機能として、AWS CloudTrailがAmazon Qコンソールと統合され、自然言語によるアカウントアクティビティの調査が可能になりました。お客様はクエリの記述やログの手動解析なしに、トレイル設定の確認、セキュリティ調査、運用トラブルシューティングを行えます。Amazon QコンソールはCloudTrailトレイル、CloudWatchロググループ、イベントデータストアをクエリし、実際のアクティビティに基づく回答を提供します。本アップデートは、セキュリティ監査、コンプライアンス、運用トラブルシューティングを行うお客様に適しています。特に、クエリを書かずに調査したいセキュリティ担当者や運用担当者にとって有益です。CloudTrailの設定が適切かどうかの確認、ログカバレッジのギャップ特定、追跡中のデータイベントソースの確認が可能です。セキュリティ調査では、特定のIAMロールに誰がアクセスしたか、VPC設定にどのような変更が加えられたか、過去1週間に不正アクセスの試みがあったかを質問できます。運用トラブルシューティングでは、特定リソースの作成・削除者の特定、エラーを発生させているAP
