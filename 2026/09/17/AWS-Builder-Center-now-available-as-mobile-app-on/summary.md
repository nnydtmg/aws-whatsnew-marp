# AWS Builder Center がiOS・Androidのモバイルアプリで利用可能に

AWS Builder Center now available as mobile app on iOS and Android

**カテゴリ:** What's New
**公開日:** 2026-09-17
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-builder-center-now-available-as-mobile-app/)

## 要約

AWS Builder CenterのモバイルアプリがiOSおよびAndroidで利用可能となり、ビルダーはどこからでもコミュニティリソースにアクセスできるようになりました。この更新はモバイルで学習やイベント管理を行いたい世界中のビルダーに適しております。

## このアップデートで何が変わったか

新しい機能は、AWS Builder CenterがiOSおよびAndroid向けのモバイルアプリとして利用可能になったことです。ビルダーはモバイルデバイスからトレンド記事の閲覧、600以上のAWS Skill Builderコースへのアクセス、無料サンドボックス環境でのハンズオンワークショップ管理が可能です。AWS HeroesやCommunity Buildersのフォロー、イベントカレンダー確認、プッシュ通知受信、Wishlist機能によるフィードバック提出がサポートされます。
