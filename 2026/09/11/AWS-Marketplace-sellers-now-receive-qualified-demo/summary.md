# AWS Marketplaceの販売者が資格確認済みのデモ・プライベートオファー依頼を数分で受信可能に

AWS Marketplace sellers now receive qualified demo and private offer requests in minutes

**カテゴリ:** What's New
**公開日:** 2026-09-09T21:04:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-marketplace-demo-private-offer-requests-qualification)

このページでは、AWS What's Newで発表された「AWS Marketplace sellers now receive qualified demo and private offer requests in minutes」の内容を日本語で要約し、スライド形式で確認できます。

## 要約

AWS Marketplaceの販売者は、お客様からのデモおよびプライベートオファーのリクエストを数分以内に受け取れるようになりました。本機能は、迅速な顧客対応を希望する販売者に適しております。

## このアップデートで何が変わったか

新機能として、AWS Marketplaceの販売者は資格確認済みのデモ依頼およびプライベートオファー依頼を数分以内に受け取れるようになりました。お客様がユースケースの詳細を提供すると、エージェントワークフローが評価して商談を作成し、連絡先とともにAWS Partner Centralへ届きます。以前はAWS担当者による資格確認で数日の遅延がございましたが、現在はすべてのアクティブなリードを即座に受け取れます。連絡先情報のみの場合でも、販売者はリードとして詳細を受け取れます。本アップデートは、デモ依頼やプライベートオファーのボタンを有効化したAWS Marketplace販売者に適しております。お客様の製品評価を迅速化し、調達サイクルを短縮したい販売者にとって有益でございます。
