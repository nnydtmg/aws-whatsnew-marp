# Amazon BedrockがConfluence Data Centerのネイティブコネクタに対応

Amazon Bedrock Managed Knowledge Base now supports Confluence Data Center as a native data source connector

**カテゴリ:** What's New
**公開日:** 2026-09-09T14:19:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-bedrock-managed-knowledge-base-confluence-data-center-native-data-source-connector/)

このページでは、AWS What's Newで発表された「Amazon Bedrock Managed Knowledge Base now supports Confluence Data Center as a native data source connector」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

Amazon Bedrock Managed Knowledge BaseがConfluence Data Centerのネイティブコネクタに対応し、認証情報の提供のみでコンテンツを自動的に取り込めるようになりました。セルフホスト環境の社内ナレッジをAIエージェントに簡単にご活用いただけます。

## このアップデートで何が変わったか

- 新機能は、Amazon Bedrock Managed Knowledge BaseがConfluence Data Centerをネイティブデータソースコネクタとしてサポートすることです。
- セルフホスト型のConfluence Data Centerインスタンスから、ブログやページを直接ナレッジベースへクロールできるようになりました。
- 認証情報をご提供いただくだけで、コネクタがクロール、メタデータ抽出、増分同期を自動的に処理いたします。
- フィルタを用いて特定のスペースやコンテンツタイプにクロール範囲を絞り込むことができます。
- 本更新は、セルフホスト型Confluence Data Centerを運用されているお客様に適しております。
- Confluence上の技術ドキュメントやランブックを活用した社内アシスタントを構築されたい方々にとって有益でございます。
