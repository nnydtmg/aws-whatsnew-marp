# Nx Plugin for AWS 1.0が一般提供開始、フルスタックアプリを迅速にスキャフォールディング

AWS announces Nx Plugin for AWS for scaffolding full-stack applications

## 要約

AWSは、フルスタックアプリケーションを迅速かつ安全に構築できるNx Plugin for AWSバージョン1.0を公開しました。本機能は、AIアシスタントを活用する開発者およびモノレポ開発チームに最適です。

## このアップデートで何が変わったか

Nx Plugin for AWS バージョン1.0は、フルスタックアプリケーションをAWS上でスキャフォールディングするオープンソースのツールキットです。本プラグインは、AIエージェント、MCPサーバー、API、ウェブサイト、データベースのジェネレーターを提供し、CDKまたはTerraformでインフラを定義します。AWS WAF、CloudWatch、X-Rayなどの推奨プラクティスと型安全な接続機能を備えています。本アップデートは、AIアシスタントでAWSアプリケーションを構築する開発者、セキュリティと型安全性を重視するTypeScriptおよびPythonのモノレポチームに有用です。生成されたコードはプラグインへのランタイム依存がなく、Nxマイグレーションでカスタマイズ済みワークスペースにも改善を適用できます。Apache 2.0ライセンスで追加料金なし。
