# Amazon Quick デスクトップアプリが macOS と Windows で一般提供開始

Amazon Quick desktop app is now generally available on macOS and Windows

**What's New** | 2026-09-09

---

## 概要

- Amazon QuickのデスクトップアプリがmacOSおよびWindowsで一般提供開始となり、ローカルファイル連携やデバイス間同期、バックグラウンドでのエージェント継続実行が可能になりました。

## 変更内容・新機能

Amazon QuickのデスクトップアプリがmacOSおよびWindowsで一般提供開始となりました。ローカルファイルと連携し、カレンダーやメール、ビジネスアプリとバックグラウンドで接続を維持します。会話やエージェントがデスクトップとモバイル間で同期され、コンピューターを閉じた後もエージェントが継続実行されます。本アップデートは既存のQuickユーザーや、複数デバイスで作業される方、エンタープライズ導入を検討されるお客様に適しています。
