# AWS Marketplaceが従量課金メータリング向けAIエージェントスキルを一般提供

AWS Marketplace launches an AI agent skill for usage-based metering integration

**What's New** | 2026-09-23T08:00:00

---

## 概要

- AWS Marketplaceは、AIコーディングアシスタント内で従量課金型SaaSメータリング統合を構築・デプロイ・検証できるAIエージェントスキルの一般提供を開始しました。
- 本機能は、メータリング統合を行う販売者の作業を大幅に効率化します。

---

## 前提・背景

### これまでの課題

AWS announces the general availability of the AWS Marketplace metering agent skill, an AI-guided experience that helps sellers build, deploy, and validate a usage-based (pay-as-you-go) SaaS metering integration from within their AI coding assistant.
