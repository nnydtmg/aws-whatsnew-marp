AWS Service Availability Updates

**カテゴリ:** What's New

**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-service-availability/)

## 要約

AWSサービスの可用性更新が発表され、複数のサービスがメンテナンスやサンセット、サポート終了となります。既存のお客様は継続利用可能ですが、移行計画を立てることが推奨されます。Amazon Chime SDK SIP Media ApplicationとAmazon WorkSpaces Secure Browserは2026年10月29日から新規お客様の利用が停止されるメンテナンスモードに移行します。Amazon Managed Blockchain、Amazon DevOps Guru、AWS Backint Agent for SAP ASE、AWS Infrastructure Composerがサンセットに入り、Amazon Mechanical Turkは2026年9月29日でサポート終了となりました。

## このアップデートで何が変わったか

AWSは2026年9月29日、複数サービス・機能の可用性変更を発表しました。

【メンテナンスに移行するサービス】
2026年10月29日から新規お客様は利用不可。既存利用者は継続利用可能で、AWSは運用・サポートを継続します。
- Amazon Chime SDK SIP Media Application
- Amazon WorkSpaces Secure Browser

## 詳細

AWSは2026年9月29日、複数サービス・機能の可用性変更を発表しました。

【メンテナンスに移行するサービス】
2026年10月29日から新規お客様は利用不可。既存利用者は継続利用可能で、AWSは運用・サポートを継続します。
- Amazon Chime SDK SIP Media Application
- Amazon WorkSpaces Secure Browser

【サンセットに入るサービス】
運用・サポート終了日が発表されました。替わりのサービスへの移行計画が推奨されます。
- Amazon Managed Blockchain（サポート終了: 2027年9月29日）
- Amazon DevOps Guru（サポート終了: 2027年9月30日）
- AWS Backint Agent for SAP ASE（サポート終了: 2027年9月29日）
- AWS Infrastructure Composer（スタンドアロンコンソールのサポート終了: 2026年12月7日）

【サポート終了となったサービス】
- Amazon Mechanical Turk（2026年9月29日にて利用不可）

影響を受けるお客様向けに移行ガイドが用意されており、AWSサポートチームが移行を支援します。AWS Product Lifecycle Pageで詳細を確認できます。
