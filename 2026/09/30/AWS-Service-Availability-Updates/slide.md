# AWSが複数サービスのメンテナンス移行とサンセットを発表

AWS Service Availability Updates

**What's New** | 2026-09-29T16:21:00

---

## 概要

- AWSサービスの可用性更新が発表され、複数のサービスがメンテナンスやサンセット、サポート終了となります。
- 既存のお客様は継続利用可能ですが、移行計画を立てることが推奨されます。
- Amazon Chime SDK SIP Media ApplicationとAmazon WorkSpaces Secure Browserは2026年10月29日から新規お客様の利用が停止されるメンテナンスモードに移行します。
- Amazon Managed Blockchain、Amazon DevO...

## 変更内容・新機能

AWSは2026年9月29日、複数サービス・機能の可用性変更を発表しました。

【メンテナンスに移行するサービス】
2026年10月29日から新規お客様は利用不可。既存利用者は継続利用可能で、AWSは運用・サポートを継続します。
