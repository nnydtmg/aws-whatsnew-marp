# AWS TransformがAmazon S3、EBS、EFS、FSx向けストレージ移行アセスメントを追加

AWS Transform adds storage migration assessments for Amazon S3, EBS, EFS, and FSx

**What's New** | 2026-10-21T19:10:00

---

## 概要

- AWS Transformにストレージ移行アセスメント機能が追加されました。
- オンプレミスストレージの評価と最適なAWSサービスへのマッピングが自動化され、移行担当者の作業を効率化いたします。

## 変更内容・新機能

-新機能は、AWS Transformによるオンプレミスストレージの移行アセスメントです。
- ストレージインベントリのアップロードにより、最適なサービスへの自動マッピングを行います。
- Amazon S3、Amazon EBS、Amazon EFS、Amazon FSxへの振り分けとサイズ推奨、コスト予測を実施します。
- What-ifシナリオの比較やチャットでの追加質問が可能です。
- 本アップデートは、多数のボリュームを手動分析していた移行担当者や、NAS・SANなどをお持ちのお客様に適しております。
