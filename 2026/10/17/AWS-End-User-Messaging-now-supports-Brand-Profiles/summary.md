# AWS End User Messaging が Brand Profiles のサポートを発表

AWS End User Messaging now supports Brand Profiles

**カテゴリ:** What's New
**公開日:** 2026-10-16T07:00:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-end-user-messaging-now-supports-brand-profiles)

このページでは、AWS What's Newで発表された「AWS End User Messaging now supports Brand Profiles」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

AWS End User MessagingのBrand Profiles機能により、ブランド情報を一度入力するだけで複数の登録に再利用でき、作業が効率化されます。自身のブランドや複数ブランドを管理するユーザーに適した機能です。

## このアップデートで何が変わったか

AWS End User MessagingはBrand Profilesを新たにサポートし、ブランドや会社情報を一度保存してメッセージング登録で再利用できるようになりました。SMS、RCS、WhatsAppの登録で同じ詳細を繰り返し入力する必要がなくなり、登録が迅速かつ一貫性のあるものになります。登録開始時にフィールドが自動入力され、スマートマッチ機能でAIが異なるフィールド名にも対応します。この更新は、自身のブランドで送信する方や単一アカウントで複数ブランドを管理する方に適しています。Brand ProfilesはAWS End User Messagingが利用可能なすべての商用AWSリージョンで利用できます。
