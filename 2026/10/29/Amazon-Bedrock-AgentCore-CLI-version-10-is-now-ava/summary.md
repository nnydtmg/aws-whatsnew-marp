# Amazon Bedrock AgentCore CLI 1.0が一般提供開始

Amazon Bedrock AgentCore CLI version 1.0 is now available

**カテゴリ:** What's New
**公開日:** 2026-10-28T20:00:00
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-bedrock-agentcore-cli-version-1-0-available/)

このページでは、AWS What's Newで発表された「Amazon Bedrock AgentCore CLI version 1.0 is now available」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

Amazon Bedrock AgentCore CLIバージョン1.0が一般提供開始され、起動の高速化と柔軟なリソース操作が可能になりました。本アップデートはターミナルからAIエージェントを開発・運用する開発者に適しています。

## このアップデートで何が変わったか

AWSはAmazon Bedrock AgentCore CLIバージョン1.0（@aws/agentcore 1.0.0）の一般提供開始を発表しました。起動の高速化、一貫したコマンド構造、より多くのAgentCoreリソースへの対応が追加されました。バージョン1.0では、プロジェクトワークフローを使うことも、プロジェクトへ追加せずにハーネス、ランタイム、メモリ、アイデンティティ、ゲートウェイ、ペイメントを直接操作することもできます。既存リソースをIDまたはARNで呼び出し、インタラクティブシェルを開き、ハーネスをエクスポートし、検索可能なメニュー、リソースピッカー、ガイド付きワークフローを利用できます。一貫したグローバルフラグにより、リージョン選択、JSON出力、デバッグ、バージョン情報を全コマンドで利用できます。既存プロジェクトはagentcore migrateコマンドでAgentCoreバージョン1へ移行できます。npmからインストール可能です。本アップデートは、ターミナルからAIエージェントを作成、開発、デプロイ、運用する開発者に適しています。
