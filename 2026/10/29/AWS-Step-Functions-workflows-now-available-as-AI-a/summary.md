# AWS Step Functions ワークフローが AI エージェントのツールとして利用可能に

AWS Step Functions workflows now available as AI agent tools

**カテゴリ:** What's New
**公開日:** 2026-10-29
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/10/step-functions-workflows-ai-agent-tools/)

このページでは、AWS What's Newで発表された「AWS Step Functions workflows now available as AI agent tools」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

AWS Step FunctionsのワークフローがAmazon Bedrock AgentCore Gatewayを通じてAIエージェントのツールとして利用可能になりました。既存ワークフローの実行と照会により、業務プロセスを一貫して自動化できます。

## このアップデートで何が変わったか

新機能は、AWS Step FunctionsのワークフローをAmazon Bedrock AgentCore Gateway経由でAIエージェントのツールとして利用できることです。エージェントが実行タイミングと入力を判断し、Step Functionsが定義どおりに各ステップを実行いたします。既存のStandardおよびExpressワークフローをツールとして利用でき、実行状況の照会も可能です。本アップデートは、AIエージェントで業務プロセスを自動化したいお客様や、カスタマーサポートおよび運用担当のお客様に適しております。
