# AWS Continuumがコード脆弱性検出・修復を自動化、一般提供開始

AWS Continuum for code vulnerabilities is now generally available

**カテゴリ:** What's New
**公開日:** 2026-10-22
**元記事:** [AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-continuum-for-code-vulnerabilities-is-now-generally-available)

## 要約

AWS Continuum for code vulnerabilitiesが一般提供開始となり、コードの脆弱性を効率的に発見から修復まで行えるようになりました。既存のAWSセキュリティサービスをご利用の開発者の皆様に適しています。

## このアップデートで何が変わったか

AWS Continuum for code vulnerabilitiesが一般提供開始となりました。この機能はコードの脆弱性を機械速度で発見、検証、優先順位付け、修復いたします。お客様のAWS環境からコンテキストグラフを構築し、既存の検出結果を取り込みコードをスキャンしてサンドボックスで悪用可能性を確認します。ビジネス影響に基づいて優先順位を付け、修復パッチをプルリクエストとして開発者ワークフローに提供します。この更新はAmazon GuardDutyやAWS Security Hubなどの既存のAWSセキュリティサービスをご利用のお客様に適しています。
