# AWS Continuum for code vulnerabilities が一般提供開始

AWS Continuum for code vulnerabilities is now generally available

**カテゴリ:** AWS Blog
**公開日:** 2026-10-22T20:33:10
**元記事:** [元記事](https://aws.amazon.com/blogs/aws/aws-continuum-for-code-vulnerabilities-is-now-generally-available/)

このページでは、AWS What's Newで発表された「AWS Continuum for code vulnerabilities is now generally available」の内容を日本語で要約し、スライド形式で確認できます。

---

## 要約

AWS Continuum for code vulnerabilitiesが一般提供開始となり、悪用可能な脆弱性の検証と修正提案を自動化いたします。大規模なコード資産を抱える組織のセキュリティ運用効率化に貢献いたします。

## このアップデートで何が変わったか

【追加情報】
- 2026年6月のAWS Summit NYCでgated previewとして発表され、2026年10月22日に一般提供開始
- 有効地域: US East (N. Virginia) と US West (Oregon)
- コンテキストグラフ: コードリポジトリとAWS環境（AWS Configリソース・ネットワーク構成）から構築
- Collectorをコード実行アカウント・リージョンに設置し、ネットワーク到達性と攻撃経路を評価
- ビジネスクリティカルなシステム（顧客データストア・決済パイプライン・認証サービス）への近さで優先度を決定
- 証拠レベル：静的解析で証明済み、再現可能な場合はサンドボックスで攻撃を実行しPoCコード付与
- 修正はコードパッチ・依存関係アップグレード・設定変更としてプルリクエストで提案
- 全ての修正は人による承認が必須（human-in-the-loop）。将来は信頼度に応じ自動適用も可能に
- コードソース: GitHub統合 または Amazon S3バケット
- スキャンはスケジュール実行またはオンデマンド実行
- モデル非

## 対象ユーザー

AWS Continuum for code vulnerabilitiesが一般提供開始となりました。本機能はコードの脆弱性を検出および検証し、悪用可能性とビジネス影響度に基づいて優先順位を付けます。修正はパッチまたはプルリクエストとして提案され、人による承認後に適用されます。コードリポジトリとAWS環境のコンテキストから攻撃経路と影響範围を評価いたします。大規模なアプリケーション資産を運用し、多数のスキャナー検出結果を処理する組織に適しております。セキュリティおよび開発チームの連携が必要なお客様にご活用いただけます。
