# AWS Lambda Web Functions が発表 — コード変更なしでWebアプリをデプロイ

Announcing AWS Lambda Web Functions

**AWS Blog** | 2026-10-12T22:34:47

---

## 概要

- AWS Lambda Web Functionsは、標準的なHTTPウェブアプリケーションをコードの書き換えなしでLambda上にデプロイできる新機能です。
- Express、Hono、Fastify、Next.jsなどのNode.jsフレームワークを単一コマンドでデプロイでき、スケーリング・マルチリージョン配信・アクティブCPU課金を自動処理します。
- ウェブアプリケーションやAPIバックエンドを構築する開発者に適しています。
