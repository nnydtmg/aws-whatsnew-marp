# AWS Well-Architected Agentがプレビューで利用可能に

AWS Well-Architected Agent is now available in preview

**What's New** | 2026-10-01T20:00:00

---

## 概要

- AWS Well-Architected Agentのプレビューが提供開始されました。
- AWSサポートプランをご利用のお客様は、AIによるインフラ最適化と優先順位付き推奨事項をご活用いただけます。

## 変更内容・新機能

- 新機能は、AWS Trusted AdvisorとAWS Well-Architected Toolの次世代進化形であるAWS Well-Architected Agentのプレビュー提供です。
- 本機能は、コスト、セキュリティ、パフォーマンス、信頼性を分析し、ビジネス目標に基づく優先順位付き推奨事項とIaC修正を提供します。
- 本アップデートは、AWSサポートプランをご利用のお客様およびインフラ最適化を必要とするチームに適しています。
